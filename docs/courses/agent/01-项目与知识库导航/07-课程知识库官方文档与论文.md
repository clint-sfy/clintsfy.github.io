# 课程知识库、官方文档与论文

项目 README 适合找入口，规范和论文适合确认概念边界。下面的资源用于补齐背景，不替代本课程按依赖顺序的文章。原始论文只说明研究中的方法和实验，不能自动变成生产安全保证；官方文档也可能随着版本迁移，统一记录查看日期 **2026-10-07**。

## Hugging Face Agents Course

官方入口：[课程 Introduction](https://huggingface.co/learn/agents-course/en/unit0/introduction)

- **解决的问题**：以循序课程解释 Agent、工具、框架、检索和评测，并配合可运行实验。
- **推荐学习内容**：把 Unit 1 的基础概念作为入门补充，遇到框架 API 时回到本课程的协议与边界文章。
- **前置知识**：Python 基础；能够阅读英文技术文档。
- **学习阶段**：入门。
- **阅读深度**：专题查阅。
- **推荐目录/文章**：Introduction、What is an Agent?、Tools、Agentic frameworks。
- **与 DeepSeek Harness 对应关系**：课程抽象可作为 dsh driver、tool、memory 和 multi-agent 对照的入门词典。
- **查看日期**：2026-10-07。

## Anthropic: Building effective agents

官方入口：[原文](https://www.anthropic.com/research/building-effective-agents)

- **解决的问题**：总结从简单 prompt chain 到 workflow 和 agent 的选择、边界和工程取舍。
- **推荐学习内容**：精读 augmented LLM、workflow、agent、orchestrator-workers、evaluator-optimizer，并记录何时不该增加复杂度。
- **前置知识**：Agent Loop、Workflow、Evals；第 02、09、10 章。
- **学习阶段**：进阶。
- **阅读深度**：专题查阅。
- **推荐目录/文章**：Building blocks、Workflows、Agents、When to use which pattern。
- **与 DeepSeek Harness 对应关系**：Workflow/agent 的边界帮助定位 dsh 是否需要插件扩展，而不是把所有任务都变成多 Agent。
- **查看日期**：2026-10-07。

## OpenAI Cookbook Agents 章节

官方入口：[Agents 主题](https://cookbook.openai.com/topic/agents)

- **解决的问题**：以短示例呈现 Responses、工具、handoff、tracing 和评测的组合方式。
- **推荐学习内容**：运行无需网络和密钥的结构化示例；需要模型的代码先检查环境变量、失败提示和成本。
- **前置知识**：Python 基础；第 02–04、10 章。
- **学习阶段**：进阶。
- **阅读深度**：运行实验。
- **推荐目录/文章**：agents topic、tool calling、structured outputs、evals。
- **与 DeepSeek Harness 对应关系**：示例中的 tool call、handoff、trace 可以映射到 dsh driver/plugin/event 三层。
- **查看日期**：2026-10-07。

## Datawhale LLM Cookbook

官方入口：[GitHub](https://github.com/datawhalechina/llm-cookbook)

- **解决的问题**：提供中文大模型应用、提示、工具调用和 RAG 的入门资料与实验入口。
- **推荐学习内容**：只把与 Agent 工程相关的章节作为中文补充；对 API/模型版本回到官方文档核对。
- **前置知识**：Python 基础；能够运行 notebook 或脚本。
- **学习阶段**：入门。
- **阅读深度**：案例参考。
- **推荐目录/文章**：大模型应用基础、函数调用、RAG、评测相关章节。
- **与 DeepSeek Harness 对应关系**：中文资料帮助补齐 driver、tool、context 词汇，不替代 dsh 官方源码和安全说明。
- **查看日期**：2026-10-07。

## Model Context Protocol Security Best Practices

官方入口：[MCP 2026-07-28 Specification 的 Security and Trust](https://modelcontextprotocol.io/specification/2026-07-28) · [规范仓库](https://github.com/modelcontextprotocol/modelcontextprotocol)

- **解决的问题**：明确 MCP token audience、confused deputy、SSRF、日志和不可信输入的安全边界。
- **推荐学习内容**：按 2026-07-28 Specification 的 Security and Trust、Consent、Data Privacy、Tool Safety 阅读；任何 tool 结果都不能直接升级为系统指令，旧安全页面只作为迁移对照。
- **前置知识**：MCP 生命周期和 OAuth 基本概念；第 06、10 章。
- **学习阶段**：生产工程。
- **阅读深度**：主线精读。
- **推荐目录/文章**：Token passthrough、Confused deputy、SSRF、User consent and data handling。
- **与 DeepSeek Harness 对应关系**：MCP Server 的授权边界应与 dsh plugin 的 capability 和审批边界叠加，而不是互相替代。
- **查看日期**：2026-10-07。

## ReAct: Synergizing Reasoning and Acting

原始论文：[arXiv:2210.03629](https://arxiv.org/abs/2210.03629)

- **解决的问题**：解释 reasoning 与 action/observation 交错的 Agent Loop 思路和可解释轨迹。
- **推荐学习内容**：精读 action-observation loop、知识获取与异常处理，不把论文轨迹直接当成生产安全方案。
- **前置知识**：Model、Tool、Observation、StopReason；第 02–04 章。
- **学习阶段**：入门。
- **阅读深度**：主线精读。
- **推荐目录/文章**：Introduction、ReAct prompting、Action spaces、Experiments。
- **与 DeepSeek Harness 对应关系**：ReAct loop 是 dsh driver 迭代工具和事件的理论参照，dsh 还增加 plugin/session/safety 层。
- **查看日期**：2026-10-07。

## Toolformer

原始论文：[arXiv:2302.04761](https://arxiv.org/abs/2302.04761)

- **解决的问题**：研究模型学习决定是否调用外部 API、如何传参及如何使用返回结果。
- **推荐学习内容**：重点理解 API call token、参数和结果拼接，结合第 04 章区分训练能力与运行时安全。
- **前置知识**：Message、Tool schema、ToolResult；第 03、04 章。
- **学习阶段**：进阶。
- **阅读深度**：专题查阅。
- **推荐目录/文章**：API calls、Self-supervised data、Tool use evaluation、Limitations。
- **与 DeepSeek Harness 对应关系**：模型选工具只是 dsh driver 的一部分，插件注册、权限、审批和审计仍由 Harness 负责。
- **查看日期**：2026-10-07。

## RAG Survey

原始论文：[Retrieval-Augmented Generation for Large Language Models: A Survey](https://arxiv.org/abs/2312.10997)

- **解决的问题**：系统梳理 RAG 的数据、检索、增强、生成和评测组件及其边界。
- **推荐学习内容**：按 retrieval、augmentation、generation 和 evaluation 对照第 08 章的本地最小管线。
- **前置知识**：Embedding、检索、Citation；第 08 章。
- **学习阶段**：进阶。
- **阅读深度**：专题查阅。
- **推荐目录/文章**：RAG taxonomy、Retrieval、Augmentation、Evaluation。
- **与 DeepSeek Harness 对应关系**：RAG 输出可作为 dsh context provider 或 tool result；权限过滤和引用仍需 Harness/应用层负责。
- **查看日期**：2026-10-07。

## A Programming Paradigm for Spatiotemporal Composability

原始论文：[arXiv:2507.17979](https://arxiv.org/abs/2507.17979)

- **解决的问题**：解释 Cordis 的时空可组合插件范式，为理解 DeepSeek Harness 的运行时提供原始材料。
- **推荐学习内容**：在读完第 02–10 章和四个对照项目后精读 Context、service、event、scope 和生命周期。
- **前置知识**：Plugin、Hook、Event、Session；第 07、09、11 章。
- **学习阶段**：生产工程。
- **阅读深度**：主线精读。
- **推荐目录/文章**：Context and composability、Spatiotemporal model、Plugin lifecycle、Examples。
- **与 DeepSeek Harness 对应关系**：这是理解 dsh Cordis、Everything is a Plugin 和事件系统的核心原始材料。
- **查看日期**：2026-10-07。

## 读论文的最小记录模板

读完论文或长文后，至少记录：它解决的问题、假设的输入输出、核心状态或数据结构、实验如何测量、哪些结论依赖特定模型/数据集、以及如何映射到本课程的 Agent Loop。没有这些边界时，论文中的方法名不应直接写进生产设计结论。
