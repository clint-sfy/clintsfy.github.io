# 学习地图与资源使用方法

本章是可随时打开的资源导航，不是开始基础课前必须背完的理论章节。它把官方项目、协议、课程和论文按“要解决的问题”分类，并为每条记录注明前置知识、阅读阶段、阅读深度、推荐入口以及和 DeepSeek Harness 的对应关系。

## 怎么走这条路线

学习者应当已经能用 Python 编写函数、读取 JSON、处理异常并运行命令行脚本。本课程不重复讲 Java、Python 或 TypeScript 的通用语法；遇到源码中的语言障碍时，回到对应语言课程单独补齐即可。

第 02–10 章遵循认知依赖顺序。每一章的第一篇是章首导读或该章的主线入口，文章中的代码骨架以 Python 为主。第 11 章再把前面形成的模型映射到五个项目的源码结构。

## 资源字段与阅读深度

每条记录都提供以下字段，方便以后更新而不退化成链接堆积：

- **解决的问题**：这条资源在系统中负责哪一类边界，不复述项目宣传语。
- **推荐学习内容**：第一次打开时应先做什么、读什么、跑什么。
- **前置知识**：直接开始前需要掌握的课程概念或工程能力。
- **学习阶段**：`入门`、`进阶` 或 `生产工程`。
- **阅读深度**：`主线精读`、`专题查阅` 或 `案例参考`。
- **推荐目录/文章**：把入口缩小到可以执行的阅读范围。
- **与 DeepSeek Harness 对应关系**：说明可以比较的 driver、plugin、session、skill、hook、event 或安全边界；不把对照关系写成实现等价。
- **查看日期**：本批记录统一核对于 **2026-10-07**。版本敏感内容以后应重新核对官方页面。

## 更新边界

本页是大纲预览和导航，不承诺外部项目 API 永久稳定。涉及密钥、浏览器登录、文件写入、Shell 或网络操作的资源，先在无敏感数据的本地环境阅读权限和安全说明；课程文章会给出模拟执行、显式审批和失败提示。
