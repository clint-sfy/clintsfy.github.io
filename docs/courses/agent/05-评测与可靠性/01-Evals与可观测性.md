# Evals 与可观测性

Agent 的输出具有非确定性，只有“演示成功一次”远远不够。工程上需要保存轨迹，并对关键能力持续评测。

## 建议记录

- 输入、模型版本、关键配置与上下文摘要；
- 每次工具调用的参数、耗时、返回和错误；
- 状态转移、重试、人工介入与停止原因；
- token、延迟和成本；
- 最终产物及其验证结果。

## 评测分层

1. **确定性单元测试**：schema、解析器、权限规则、状态机。
2. **轨迹评测**：是否选对工具、参数是否合理、是否出现无效循环。
3. **结果评测**：正确性、完整性、引用、风格和安全性。
4. **线上指标**：成功率、人工接管率、延迟、成本与回退率。

先建立小而稳定的黄金任务集，再逐步加入真实失败样本。每次修复都应把失败样本变成回归用例。
