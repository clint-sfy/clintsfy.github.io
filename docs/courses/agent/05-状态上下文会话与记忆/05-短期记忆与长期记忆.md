# 短期记忆与长期记忆

本篇用于建立「短期记忆与长期记忆」在 Agent 系统中的基本边界。学完后知道它解决什么问题、如何与前后组件衔接，以及实现时需要关注的关键约束。

## 知识点

1. `ShortTermMemory` 与 `LongTermMemory`。
2. `MemoryScope`：用户、租户、项目和会话。
3. 写入、召回、更新、删除和保留。
4. 记忆进入 Context 前的权限与来源。
