# Agent Skills 设计

Skill 用来把一类任务的稳定做法沉淀成可复用能力。它通常不只是提示词，还可以包含脚本、模板、参考资料、验收步骤和工具使用约束。

## 一个好 Skill 的特征

- 触发范围清晰，不会什么任务都抢着执行；
- 先给最少必要指令，需要时再读取参考资料；
- 把确定性工作交给脚本，把判断留给模型；
- 明确输入、产物、失败条件和验证方式；
- 不把密钥、账号或环境偶然状态写进技能正文；
- 能通过真实案例和回归测试验证。

## Skills 与 MCP 的区别

MCP 更像能力接口：告诉 Agent“能调用什么”。Skill 更像工作方法：告诉 Agent“这类任务应该怎样完成”。两者可以组合，例如 Skill 规定调研流程，MCP Server 提供搜索、数据库或项目管理工具。
