# Java基础快速入门

这是一套参考“先语言、再库、再运行时、最后工程化”的 Java 补习路线。内容从能写出第一个程序开始，逐步过渡到集合与函数式编程、并发与 JVM，再落到 Maven、测试、数据库和设计实践。每一篇都保留目标、知识点、实践任务、易错点和复习清单，适合边学边写代码。

## 学习建议

1. 本系列统一使用 JDK 20，IDE 可选 IntelliJ IDEA；先用命令行完成一次 `javac`、`java` 和 `jar` 流程，再依赖 IDE。JDK 20 不是 LTS，学习预览特性时需明确启用 `--enable-preview`。
2. 每篇先读“学习目标”，随后把实践任务写成独立的小项目；代码不要只停留在复制示例，至少做一次改需求、加测试或压测。
3. 先掌握对象模型和集合，再学习 Lambda、Stream 与并发；遇到抽象概念时回到可运行的最小示例，用日志、调试器和线程转储验证推断。
4. 每完成一个阶段，做一次复盘：能否不用查资料解释核心概念？能否写出边界测试？能否说明选择某个 API 的理由？
5. 最终项目建议采用“命令行或 REST 服务 + 数据库 + 单元测试 + 日志 + Maven”的最小闭环，并在 JVM、并发、设计模式章节之后迭代优化。

## 进阶出口

完成路线后，可以按目标继续深入：Spring Boot 与 Web、MyBatis/JPA、消息队列、容器化部署、性能工程、分布式系统或 Java 源码阅读。进阶学习应围绕真实问题展开，优先记录指标、约束、取舍和验证结果。
