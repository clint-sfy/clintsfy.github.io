# 学习路线与目标

Kafka 是分布式事件流平台。学习时先问三个问题：谁写入事件？事件按什么顺序存储？谁从哪个位置读取？这分别对应 Producer、Topic 分区日志和 Consumer 的 offset。

## 为什么按这个顺序学

先用命令行发一条消息，能看见原始行为；再写 Java 客户端，才知道 API 映射到哪一步。理解分区与 offset 后，再学消费组、ACK、复制和故障恢复。直接从 Spring 注解入手，容易把自动提交、重试和重复消费混在一起。

## 学完应能做什么

- 画出 Producer → Broker 分区 → Consumer Group 的数据流。
- 用 Java 创建 Topic、发送消息、读取消息和处理失败。
- 解释“至少一次”为什么会重复，以及业务如何幂等。
- 区分消息已到 Broker、已复制、已被消费和业务已完成。
