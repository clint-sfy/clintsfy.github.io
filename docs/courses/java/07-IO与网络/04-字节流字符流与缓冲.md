# 字节流、字符流与缓冲

## 学习目标

- 能按字节或字符选择 InputStream、OutputStream、Reader 和 Writer。
- 会组合缓冲层和显式 Charset，避免逐字节读写与乱码。
- 能处理 try-with-resources、EOF、mark/reset、压缩流和数据流边界。

## 核心知识点

### 专业术语

- **InputStream/OutputStream**：以 `int` 或 `byte[]` 读写原始字节。
- **Reader/Writer**：按字符读写，并通过 Charset 把字节解码或编码。
- **Buffered**：用内存缓冲减少底层系统调用，不改变数据语义。
- **EOF（End of File）**：读取结束信号，字节流通常用 `-1` 表示。

### 白话解释与边界

图片、压缩包和协议帧使用字节流；文本才在确定编码后使用字符流。`BufferedInputStream` 和 `BufferedReader` 只是加速层，不会把字节自动变成正确字符。所有流都要关闭，写出流尤其要 flush/close，否则末尾缓冲内容可能尚未落盘。

## 常用用法

### `InputStream.read`：读取一个字节或一批字节

`read()` 返回的是 0–255 或 `-1`，不能直接当作有符号 byte；大量数据应使用字节数组重载，避免逐字节调用造成过多系统调用。

```java
// 说明：InputStream.read：读取一个字节或一批字节。
import java.io.ByteArrayInputStream;
import java.io.InputStream;

public class InputStreamReadDemo {
    public static void main(String[] args) throws Exception {
        try (InputStream input = new ByteArrayInputStream(new byte[]{65, 66})) {
        // 初始状态：input 当前为 new ByteArrayInputStream(new byte[]{65, 66})) {。
            int first = input.read();
            // 关键变化：int first = input.read(); 的返回值写入 first，调用后 first 保存该具体结果。
            byte[] rest = input.readAllBytes();
            System.out.println((char) first + " / " + rest.length);
            // 输出：A / 1
        }
    }
}
```

### `OutputStream.write`：写出字节

`write(int)` 只写最低 8 位；写文本前先用明确 Charset 编码。

```java
// 说明：OutputStream.write：写出字节。
import java.io.ByteArrayOutputStream;
import java.io.OutputStream;
import java.nio.charset.StandardCharsets;

public class OutputStreamWriteDemo {
    public static void main(String[] args) throws Exception {
        try (OutputStream output = new ByteArrayOutputStream()) {
        // 初始状态：output 当前为 new ByteArrayOutputStream()) {。
            output.write("Java".getBytes(StandardCharsets.UTF_8));
            // 关键变化：output.write("Java".getBytes(StandardCharsets.UTF_8));；output 写入具体参数 "Java".getBytes(StandardCharsets.UTF_8)，对象状态或输出内容随之改变。
            output.flush();
            System.out.println(output.toString());
            // 输出：Java
        }
    }
}
```

这里的 `ByteArrayOutputStream` 不需要真正关闭，但统一使用 try-with-resources 便于替换成文件或网络流。

### 缓冲字节传输：减少底层读写次数

缓冲流减少底层访问次数；如果底层已经是内存流，性能收益很小，但模式在替换为文件或 Socket 时仍然通用。

```java
// 说明：缓冲字节传输：减少底层读写次数。
import java.io.ByteArrayInputStream;
import java.io.ByteArrayOutputStream;
import java.io.BufferedInputStream;
import java.io.BufferedOutputStream;

public class BufferedByteStreamDemo {
    public static void main(String[] args) throws Exception {
        var source = new ByteArrayInputStream(new byte[]{1, 2, 3});
// 关键变化：source 接收表达式 new ByteArrayInputStream(new byte[]{1, 2, 3}) 的计算结果。
// 初始状态：source 的初始值为 new ByteArrayInputStream(new byte[]{1, 2, 3})。
        var target = new ByteArrayOutputStream();
        try (var input = new BufferedInputStream(source);
             var output = new BufferedOutputStream(target)) {
            input.transferTo(output);
        }
        System.out.println(target.size());
        // 输出：3
    }
}
```

### `InputStream.transferTo`：直接转发字节

`transferTo` 适合完整转发，但不会替调用方关闭输入或输出，也不会限制总字节数；网络输入要配合大小上限和超时。

```java
// 说明：InputStream.transferTo：直接转发字节。
import java.io.ByteArrayInputStream;
import java.io.ByteArrayOutputStream;

public class TransferToDemo {
    public static void main(String[] args) throws Exception {
        var input = new ByteArrayInputStream(new byte[]{10, 20});
        // 初始状态：input 当前为 new ByteArrayInputStream(new byte[]{10, 20})。
        var output = new ByteArrayOutputStream();
        long count = input.transferTo(output);
        // 关键变化：long count = input.transferTo(output); 的返回值写入 count，调用后 count 保存该具体结果。
        System.out.println(count + " / " + output.size());
        // 输出：2 / 2
    }
}
```

### 读写字符：使用字符流传输文本

字符流按 UTF-16 `char` 处理，不等于按 Unicode 码点处理；表情等补充字符可能占用两个 `char`。

```java
// 说明：读写字符：使用字符流传输文本。
import java.io.StringReader;
import java.io.StringWriter;

public class CharacterStreamDemo {
    public static void main(String[] args) throws Exception {
        try (var reader = new StringReader("你好"); var writer = new StringWriter()) {
// 关键变化：reader 接收表达式 new StringReader("你好"); var writer = new StringWriter()) { 的计算结果。
// 初始状态：reader 的初始值为 new StringReader("你好"); var writer = new StringWriter())。
            writer.write(reader.read());
            char[] rest = new char[1];
            reader.read(rest);
            writer.write(rest);
            System.out.println(writer);
            // 输出：你好
        }
    }
}
```

### 转换字节与字符：显式指定 `Charset`

字节和字符边界必须明确指定同一 Charset；不要依赖 `new InputStreamReader(input)` 的平台默认编码。

```java
// 说明：转换字节与字符：显式指定 Charset。

import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.nio.charset.StandardCharsets;

    public static void main(String[] args) throws Exception {
        byte[] bytes = "你好".getBytes(StandardCharsets.UTF_8);

// 初始状态：bytes 的初始值为 "你好".getBytes(StandardCharsets.UTF_8)。

            System.out.println(reader.readLine());
            // 输出：你好
        }
    }
}
```

### `BufferedReader(Reader)`：为字符输入增加缓冲

`BufferedReader` 接收已有的 `Reader` 并在其上增加缓冲，构造时不读取数据，关闭外层 `reader` 时会继续关闭传入的 `source`。

```java
    // 输出：first

```

`readLine` 不返回行尾换行符；行很长或输入不可信时仍要考虑内存上限。

### 缓冲文本输出：选择异常透明或格式化写入

`BufferedWriter` 适合受控文本写出；`PrintWriter` 便于格式化，但默认会吞掉部分 I/O 异常并通过 `checkError()` 报告，不能误当成异常透明的 Writer。

```java
// 说明：缓冲文本输出：选择异常透明或格式化写入。
import java.io.BufferedWriter;
import java.io.StringWriter;
import java.io.PrintWriter;

public class TextWriterDemo {
    public static void main(String[] args) throws Exception {
        var target = new StringWriter();
// 关键变化：target 接收表达式 new StringWriter() 的计算结果。
// 初始状态：target 的初始值为 new StringWriter()。
        try (var writer = new BufferedWriter(target)) {
            writer.write("java");
            writer.newLine();
            writer.write("api");
        }
        try (var print = new PrintWriter(target)) {
            print.println("done");
        }
        System.out.println(target.toString().replace(System.lineSeparator(), "|"));
        // 输出：java|api|done|
    }
}
```

### `Charset`：显式编码与解码

优先使用 `StandardCharsets` 常量，避免拼写错误和不必要的受检异常；协议、文件格式和数据库连接都应记录字符集约定。

```java

    public static void main(String[] args) {

        // 输入：Charset charset = StandardCharsets.UTF_8; 使用语句中的具体实参或初始值，charset 从这里进入后续操作。

        // 关键变化：byte[] bytes = "Java".getBytes(charset)；bytes 接收 getBytes(charset) 的返回值，当前值变为这次调用得到的具体结果。
// 初始状态：bytes 的初始值为 "Java".getBytes(charset)。
        System.out.println(new String(bytes, charset));
        // 输出：Java
    }
}
```
## 不常用但需要知道

### 回看输入：标记位置后复位

是否支持 mark、回看范围多大由具体流决定；不确定时使用 `BufferedInputStream` 或自己缓存数据，不能假定所有网络流都可 reset。

```java
import java.io.ByteArrayInputStream;

public class MarkResetDemo {
    public static void main(String[] args) throws Exception {
        try (var input = new ByteArrayInputStream(new byte[]{1, 2, 3})) {
// 关键变化：input 接收表达式 new ByteArrayInputStream(new byte[]{1, 2, 3})) { 的计算结果。
// 初始状态：input 的初始值为 new ByteArrayInputStream(new byte[]{1, 2, 3}))。
            System.out.println(input.read());
            // 输出：1
            input.mark(2);
            System.out.println(input.read() + ", " + input.read());
            // 输出：2, 3
            input.reset();
            System.out.println(input.read());
            // 输出：2
        }
    }
}
```

### 读写基本类型：使用配对二进制端点

Data 流是 Java 定义的二进制格式，不是通用 JSON 或跨语言协议；读写顺序、类型和端序必须由双方固定。

```java
import java.io.ByteArrayInputStream;
import java.io.ByteArrayOutputStream;
import java.io.DataInputStream;
import java.io.DataOutputStream;

public class DataStreamDemo {
    public static void main(String[] args) throws Exception {
        var bytes = new ByteArrayOutputStream();
// 关键变化：bytes 接收表达式 new ByteArrayOutputStream() 的计算结果。
// 初始状态：bytes 的初始值为 new ByteArrayOutputStream()。
        try (var out = new DataOutputStream(bytes)) {
            out.writeInt(20);
            out.writeUTF("java");
        }
        try (var in = new DataInputStream(new ByteArrayInputStream(bytes.toByteArray()))) {
            System.out.println(in.readInt() + " / " + in.readUTF());
            // 输出：20 / java
        }
    }
}
```


### `PushbackInputStream`：把字节推回输入

推回缓冲区容量有限，适合词法分析或协议前缀探测；复杂回看不要无限 unread。

```java
            input.unread(first);
            System.out.println((char) input.read());
            // 输出：A
        }
    }
```


### `IOException`：构造带原因的 I/O 异常

封装底层失败时保留 `cause`，让上层仍能追踪根因。

```java
import java.io.IOException;
var cause = new IllegalStateException("disk unavailable");
// 初始状态：cause 当前为 new IllegalStateException("disk unavailable")。
var error = new IOException("save failed", cause);
// 关键变化：var error = new IOException("save failed", cause); 的返回值写入 error，调用后 error 保存该具体结果。
System.out.println(error.getMessage());
// 输出：save failed、disk unavailable
System.out.println(error.getCause().getMessage());
// 输出：System.out 调用参数为 error.getCause().getMessage()。
```

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.StringReader;
import java.io.StringWriter;

public class StreamDemo {
    public static void main(String[] args) throws Exception {
        StringWriter storage = new StringWriter();
// 初始状态：storage 的初始值为 new StringWriter()。
        try (var writer = new BufferedWriter(storage)) {
            writer.write("Java");
            writer.newLine();
            writer.write("I/O");
        }
        try (var reader = new BufferedReader(new StringReader(storage.toString()))) {
            System.out.println(reader.readLine());
            // 输出：Java
            System.out.println(reader.readLine());
            // 输出：I/O
        }
    }
}
```

案例展示了字符、缓冲、行和资源关闭的组合；改成文件时再加 `Files.newBufferedReader/newBufferedWriter` 和显式 Charset。

## 易混点

- `InputStream.read()` 的 `-1` 是 EOF，不能把 `byte` 的负值当成结束。
- 缓冲流提高访问效率，但不改变字符集，也不自动解决半包或消息边界。
- `Reader` 按 `char` 读，不等于按 Unicode 码点读；需要码点时使用 `codePoints()`。
- `PrintWriter` 方便但可能吞异常，文件关键写入不要忽略 `checkError` 或底层 IOException。

## 课后小问

1. 为什么 `InputStreamReader` 必须传入 Charset？
答案：它负责把字节解码成字符，缺少明确编码就会依赖平台默认值。
解析：文件和网络协议应显式约定 UTF-8 等编码，读写两侧必须一致。

2. 为什么写完 `BufferedWriter` 还要关闭或 flush？
答案：数据可能仍在内存缓冲中，没有 flush/close 就未必真正写到下层。
解析：try-with-resources 既会 flush 又会关闭资源，并能在异常路径执行清理。

## 本节小结

- 字节流处理原始数据，字符流处理编码后的文本。
- 缓冲层减少系统调用，不能替代 Charset、协议边界或错误处理。
- `readLine`、`transferTo`、压缩流和数据流各有明确格式与资源边界。
- 所有流都要关闭，写出流还要确认缓冲内容已提交。

## 快速回顾

- 二进制用 InputStream/OutputStream，文本用 Reader/Writer。
- `StandardCharsets.UTF_8` 是明确编码的常用选择。
- `read()` 返回 `-1` 表示 EOF，批量读写优先使用数组或 transferTo。
- mark/reset、DataStream、GZIP 和 PrintWriter 都有额外语义与限制。
