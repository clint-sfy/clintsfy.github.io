# 网络编程与 HTTP

## 学习目标

- 理解 TCP/UDP、端口、连接、半关闭和字节序的基础概念。
- 使用 Socket 或 HttpClient 发起可靠的 HTTP 请求。
- 配置连接、读取、重试、取消和响应体关闭策略。

## 核心知识点

TCP 提供有序可靠字节流，不保留消息边界；UDP 面向数据报。HTTP 请求包含方法、URI、头和主体，响应包含状态码和主体；连接复用可减少握手成本。Java `HttpClient` 支持同步和异步请求、HTTP/2 与超时配置。网络代码必须区分连接超时、读取超时、DNS、TLS 和业务错误；重试只对幂等操作并设置退避。

## 实践任务

实现带超时的天气查询客户端（使用本地 mock 服务）：校验状态码和 Content-Type，解析 JSON，记录请求 ID，并对 429/5xx 按指数退避重试；用 Socket 写一个回显服务理解半包。

## 易错点

- 把 TCP 一次 read 当成完整消息，忽略半包和粘包。
- 没有读取或关闭响应体，连接池无法复用。
- 对 POST 等非幂等请求盲目重试，导致重复写入。
- 把网络异常、HTTP 状态和业务错误混成一个异常。

## 复习清单

- [ ] 能解释 TCP 字节流与应用层消息边界。
- [ ] 能为 HTTP 客户端配置完整超时和取消。
- [ ] 能设计安全的重试条件、退避和幂等边界。
