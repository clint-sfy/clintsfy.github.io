# 封装、继承与多态

## 学习目标

- 用访问控制和不变式完成封装，理解 protected 的边界。
- 区分重载、重写、向上转型和向下转型。
- 通过多态替换条件分支，并判断继承是否真的表达 is-a 关系。

## 核心知识点

封装隐藏表示细节，只通过稳定方法维护状态；继承复用父类契约，但子类必须满足里氏替换原则。实例方法通过动态绑定实现运行时多态，字段访问却按引用声明类型决定。重写可使用 `@Override` 校验，不能降低可见性；`final` 方法不可重写，`final` 类不可继承。优先组合，把可变化行为注入对象；只有当子类确实是父类的一种时才继承。

## 实践任务

实现支付策略：定义统一的 `Payment` 抽象，分别用银行卡、余额和模拟支付实现；结算服务只依赖抽象接口。再用一个错误的“继承复用”例子说明为什么组合更合适。

## 易错点

- 向下转型前不检查真实类型，引发 `ClassCastException`。
- 重写方法时忘记 `@Override` 或改变参数列表，实际变成重载。
- 把父类构造器当作可继承方法，或在构造阶段调用开放方法。
- 让子类依赖父类的 protected 可变状态，导致封装泄漏。
