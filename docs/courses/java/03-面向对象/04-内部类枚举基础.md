# 内部类与枚举基础

## 学习目标

- 区分静态嵌套类、成员内部类、局部类和匿名类。
- 理解内部类对外部对象的隐式引用及其序列化影响。
- 用枚举表示有限状态，并为枚举常量绑定数据和行为。

## 核心知识点

静态嵌套类不持有外部实例引用，适合辅助类型；成员内部类默认持有外部对象，可能延长生命周期。匿名类常用于一次性策略，现代代码更多使用 Lambda。枚举实例数量固定，构造器私有，可包含字段、方法和抽象行为；用 `EnumSet`、`EnumMap` 高效处理枚举集合。不要依赖 `ordinal()` 持久化业务含义。

## 实践任务

实现订单状态枚举：定义待支付、已支付、已发货、已完成、已取消及合法转换；用 `EnumMap` 配置状态描述，用参数化测试验证每条转换边。

## 易错点

- 成员内部类意外持有 Activity、请求或大对象，造成泄漏。
- 依赖枚举 ordinal 作为数据库值，新增常量后破坏历史数据。
- 在 switch 中漏处理新增枚举值。
- 用匿名类承载复杂业务，导致命名和测试困难。
