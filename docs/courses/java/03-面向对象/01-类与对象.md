# 类与对象

## 学习目标

- 理解类、对象、字段、方法、构造器和对象生命周期。
- 掌握 `this`、构造器重载、静态成员和初始化顺序。
- 用职责、协作和不变式设计小型领域对象。

## 核心知识点

类是对象的结构与行为描述，对象是运行时实例；引用变量保存对象引用而不是对象本身。构造器负责建立有效状态，`this` 区分字段与参数。静态字段属于类，实例字段属于对象；静态初始化、实例字段初始化和构造器有固定顺序。默认构造器只在没有显式构造器时生成。优先让类保持高内聚，避免暴露可随意修改的内部数据。

## 实践任务

设计 `BankAccount`：余额不能为负，存取款需要校验金额，转账要协调两个账户；禁止直接暴露余额字段，补充成功和失败场景测试，并画出一次转账涉及的对象协作。

## 易错点

- 误以为 `new` 只调用构造器，忽略对象分配和字段初始化过程。
- 直接返回可变集合字段，破坏类的不变式。
- 在构造器中调用可被子类重写的方法，导致子类字段尚未初始化。
- 把所有工具方法都写成 static，失去对象状态和职责边界。
