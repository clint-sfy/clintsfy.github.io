# JVM 内存与类加载

## 学习目标

- 区分堆、线程栈、元空间、程序计数器和本地方法栈。
- 解释加载、链接、初始化以及双亲委派的关系。
- 使用 jps、jstack、jmap、jcmd 和 JFR 获取运行时证据。

## 核心知识点

对象通常分配在堆，线程栈保存栈帧和局部变量，类元数据位于元空间；具体布局受实现和 JIT 优化影响。类加载包含加载、验证、准备、解析和初始化，主动使用会触发初始化。类的身份由类名与类加载器共同决定，不同加载器加载同名类也可能无法转换。双亲委派减少重复加载与核心类替换风险，但插件隔离常需自定义加载器。

## 实践任务

写一个可热加载的插件接口和两个 ClassLoader：记录加载器层级、类初始化日志及卸载条件；用 jcmd 查看堆、线程和类加载统计，整理一张故障排查命令表。

## 易错点

- 把栈溢出、堆溢出和元空间溢出混为一谈。
- 在静态初始化中执行复杂 I/O，导致类初始化死锁或启动失败。
- 误以为类卸载只要对象不可达，忽略类加载器可达性。
- 看到一次堆占用高就直接调大堆，没有确认分配和泄漏来源。
