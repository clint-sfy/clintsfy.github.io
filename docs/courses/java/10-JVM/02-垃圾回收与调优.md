# 垃圾回收与 JVM 调优

## 学习目标

- 理解可达性分析、分代假说、Minor/Full GC 和对象晋升。
- 读懂 GC 日志、堆转储、线程转储和 JFR 事件。
- 围绕延迟、吞吐、占用和成本制定可验证的调优方案。

## 核心知识点

GC 判断对象是否从 GC Roots 可达；短命对象和老对象的分布会影响收集效率。收集器选择取决于堆大小、延迟目标和工作负载，不能只凭“最新”决定。调优顺序是先确认指标与基线，再定位分配速率、晋升、停顿、泄漏或锁竞争，最后修改一个变量并回归。常用参数包括堆大小、GC 日志、堆转储和 OOM 自动转储，具体参数要以目标 JDK 文档为准。

## 实践任务

构造对象突增、缓存泄漏和大数组分配三类场景：采集 GC 日志与 JFR，比较不同堆大小下的吞吐和 p99 停顿，写出“现象—证据—改动—结果”报告。

## 易错点

- 只调大堆而不处理缓存引用或分配热点。
- 把 Full GC 次数直接等同于内存泄漏。
- 忽略容器内存、CPU 配额和本地内存。
- 在没有基线和压测的情况下凭经验更换收集器。

## 复习清单

- [ ] 能从 GC 日志提取停顿、频率和回收量。
- [ ] 能区分泄漏、分配过快和堆太小。
- [ ] 能写出可回滚、可比较的调优实验。
