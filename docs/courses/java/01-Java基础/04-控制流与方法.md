# 控制流与方法

## 学习目标

- 根据分支数量和循环条件选择恰当的控制流语句。
- 区分传统 `switch` 与 JDK 20 的 `switch` 表达式。
- 将校验、计算和展示拆为职责单一的方法，并理解递归边界。

## 条件分支：if/else 与 switch

`if` 的条件必须是 `boolean`，不能像某些语言那样把整数或字符串当作真假值。两三个范围判断、组合条件或需要提前返回时，`if/else if/else` 最直接。先处理非法或无需继续的情况（早返回），可减少嵌套层级。

```java
public class IfElseDemo {
    static String grade(int score) {
        if (score < 0 || score > 100) {
            return "分数无效";
        }
        if (score >= 90) return "A";
        if (score >= 60) return "及格";
        return "待改进";
    }

    public static void main(String[] args) {
        System.out.println(grade(88));
        System.out.println(grade(120));
    }
}
```

当一个值要与多个固定标签匹配时用 `switch`。传统语句使用冒号，若不想继续执行后续分支，必须写 `break`；它适用于需要在分支中执行多条语句、但不需要从 `switch` 产出值的旧式或兼容写法。

```java
public class TraditionalSwitchDemo {
    public static void main(String[] args) {
        int day = 6;
        switch (day) {
            case 1:
            case 7:
                System.out.println("周末");
                break;
            case 2:
            case 3:
            case 4:
            case 5:
            case 6:
                System.out.println("工作日");
                break;
            default:
                System.out.println("非法日期");
        }
    }
}
```

JDK 20 可使用标准的 `switch` 表达式：箭头分支不会贯穿，整个 `switch` 可以赋给变量或直接 `return`。同一结果可用逗号合并标签；需要多条语句时用代码块，并用 `yield` 交出表达式结果。这里使用的标签式表达式无需预览开关；不要把 JDK 20 中仍属预览特性的模式匹配 `switch` 混入普通项目。

```java
public class SwitchExpressionDemo {
    static int daysInMonth(int month, boolean leapYear) {
        return switch (month) {
            case 1, 3, 5, 7, 8, 10, 12 -> 31;
            case 4, 6, 9, 11 -> 30;
            case 2 -> {
                int days = leapYear ? 29 : 28;
                yield days;
            }
            default -> throw new IllegalArgumentException("月份应为 1 到 12");
        };
    }

    public static void main(String[] args) {
        System.out.println(daysInMonth(2, true));
    }
}
```

`switch` 可处理 `byte`、`short`、`char`、`int`、其包装类、`String`、枚举和相应的可转换值；表达式为 `null` 时通常会抛 `NullPointerException`。`default` 适合兜底；穷尽的枚举 `switch` 表达式可以不写它。

## 循环：重复直到条件不成立

`for` 适合已知次数或有明确计数器的遍历；初始化、条件和更新都放在一行。`while` 先判断再执行，适合次数未知、依赖外部状态的重复；`do-while` 先执行一次再判断，适合菜单至少展示一次的情形。增强 `for` 适合只读取数组或 `Iterable` 中的每个元素；它没有通用下标，遍历时也不应直接结构性修改集合。

```java
public class LoopDemo {
    public static void main(String[] args) {
        int sum = 0;
        for (int i = 1; i <= 3; i++) sum += i;

        int retry = 0;
        while (retry < 2) {
            retry++;
        }

        int shown = 0;
        do {
            System.out.println("菜单已显示");
            shown++;
        } while (shown < 1);

        for (int score : new int[]{80, 90, 100}) {
            System.out.println(score);
        }
        System.out.println(sum + "," + retry);
    }
}
```

`break` 立刻退出当前循环或 `switch`；`continue` 跳过本轮剩余语句，进入下一轮。标签应只用于“退出或继续外层循环”这类清晰场景，不能替代拆分方法；标签后必须紧跟循环语句。

```java
public class BreakContinueDemo {
    public static void main(String[] args) {
        int[] values = {3, -1, 0, 8, 9};
        for (int value : values) {
            if (value < 0) continue;
            if (value == 0) break;
            System.out.println(value);
        }

        outer:
        for (int row = 0; row < 3; row++) {
            for (int column = 0; column < 3; column++) {
                if (row == 1 && column == 1) break outer;
            }
        }
        System.out.println("已退出双层循环");
    }
}
```

循环正确性的关键是终止条件：每轮必须让控制变量向结束状态推进，且避免在循环体中意外改变边界。需要边遍历边删除时使用 `Iterator.remove()`，不要对增强 `for` 中的集合直接 `remove`，否则可能出现 `ConcurrentModificationException`。

## 方法：给一段行为取名字

方法由修饰符、返回类型、名称、参数列表和方法体组成。返回类型是调用方能得到的结果：没有结果用 `void`；任意能到达方法结尾的路径都必须满足非 `void` 方法的 `return`。方法参数是传入的数据，局部变量只在方法调用期间存在。

Java 始终**按值传递**。基本类型传的是数值副本；对象参数传的是“引用值”的副本，因此方法可以修改该对象的内容，却不能把调用方变量改为指向新对象。

```java
import java.util.List;

public class PassByValueDemo {
    static void changeNumber(int number) {
        number = 99;
    }

    static void changeList(List<String> names) {
        names.add("Lin");
        names = List.of("New Reference");
    }

    public static void main(String[] args) {
        int number = 1;
        var names = new java.util.ArrayList<String>();
        changeNumber(number);
        changeList(names);
        System.out.println(number); // 1
        System.out.println(names);  // [Lin]
    }
}
```

### 重载、可变参数与递归

重载是同一个类中同名、但参数数量、类型或顺序不同的方法。返回类型不同不足以构成重载。可变参数 `int...` 让调用者传零个或多个同类型实参；在方法体内它就是数组，且每个方法至多一个可变参数，并且必须放在最后。重载中同时存在数组和可变参数、或依赖装箱拆箱时，容易产生二义性，公共 API 应保持明确。

```java
public class OverloadVarargsDemo {
    static int max(int left, int right) {
        return left > right ? left : right;
    }

    static double max(double left, double right) {
        return left > right ? left : right;
    }

    static int sum(int... numbers) {
        int total = 0;
        for (int number : numbers) total += number;
        return total;
    }

    public static void main(String[] args) {
        System.out.println(max(2, 3));
        System.out.println(max(2.5, 3.5));
        System.out.println(sum(1, 2, 3));
    }
}
```

递归是方法调用自己。它适合天然分解为同类更小问题的场景，如树结构、目录或数学定义；每条路径都必须有基线（终止条件），并且每次调用都要向基线收敛。线性大数据量的递归会耗尽调用栈，普通计数优先循环。

```java
public class RecursionDemo {
    static long factorial(int n) {
        if (n < 0) throw new IllegalArgumentException("n 不能为负数");
        if (n <= 1) return 1;
        return n * factorial(n - 1);
    }

    public static void main(String[] args) {
        System.out.println(factorial(5)); // 120
    }
}
```

## 输入校验与职责拆分

把控制台读取、格式校验、业务计算和输出混在 `main` 中，代码很快难以测试。一个实用的最小拆分是：`main` 负责流程；校验方法只回答“是否合法”；计算方法只接收已验证数据并返回结果；展示方法只格式化结果。这样可独立传入边界值验证规则，而不必模拟控制台。

```java
public class ResponsibilityDemo {
    static boolean isValidAge(String text) {
        try {
            int age = Integer.parseInt(text);
            return age >= 0 && age <= 150;
        } catch (NumberFormatException exception) {
            return false;
        }
    }

    static int nextAge(int age) {
        return age + 1;
    }

    static String formatResult(int age) {
        return "明年年龄：" + nextAge(age);
    }

    public static void main(String[] args) {
        String input = "20";
        if (!isValidAge(input)) {
            System.out.println("请输入 0 到 150 的整数");
            return;
        }
        System.out.println(formatResult(Integer.parseInt(input)));
    }
}
```

## 易错点

- 把非布尔值写进 `if` 条件，或在传统 `switch` 漏掉 `break` 后意外贯穿。
- 在需要结果的 `switch` 表达式中忘记 `yield`，或把箭头分支误认为会继续执行下一分支。
- 写出永远不更新控制变量的 `while`，或在增强 `for` 中直接删除集合元素。
- 误以为 Java 对对象“按引用传递”，期待方法内重新赋值会改变调用方引用。
- 只改变返回类型来声明重载，或让可变参数与装箱拆箱制造不清晰的调用。
- 递归没有基线条件、没有缩小问题规模，或对很深的数据使用递归导致 `StackOverflowError`。

## 本节小结

范围和组合判断优先用 `if/else`，固定标签分派可用 `switch`；JDK 20 的箭头式 `switch` 表达式适合安全地产出一个值。循环的选择取决于是否已知次数、是否至少执行一次和是否只读遍历。方法让流程获得清晰名称与边界，Java 参数总是按值传递。校验、计算和展示分离后，代码更短、更可测试；递归必须有基线和收敛过程。
