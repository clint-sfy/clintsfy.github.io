# 控制流与方法

## 学习目标

- 熟练使用 `if`、`switch`、`for`、`while`、`do-while` 和增强 for。
- 用 `break`、`continue`、标签和早返回控制复杂流程。
- 把重复逻辑提炼为职责清晰、可单元测试的方法。

## 核心知识点

条件表达式必须得到布尔值；`switch` 支持整数、字符串、枚举和现代的表达式写法，表达式模式需要明确是否返回值。循环应先定义不变式和终止条件，避免修改迭代边界。方法应尽量单一职责，参数数量过多时可引入参数对象。递归要有基线条件，并评估栈深度。输入校验、主流程和输出格式分开，后续更容易测试。

## 实践任务

实现一个命令行菜单：读取用户选项后执行新增、查询、删除和退出；用 `switch` 分派动作，用方法封装每个用例，输入空值或非法选项时给出可恢复提示。为循环补充至少三个边界测试。

## 易错点

- `switch` 的传统语法漏写 `break` 导致贯穿执行。
- 在循环中修改集合导致 `ConcurrentModificationException`。
- 递归缺少终止条件或对大输入没有栈深度评估。
- 把业务判断、输入输出和数据存储全部塞进 `main`。

## 复习清单

- [ ] 能选择循环、递归或 Stream 的适用场景。
- [ ] 能写出无贯穿错误的 `switch`，并说明表达式与语句差异。
- [ ] 能把一个长方法拆成可命名、可测试的步骤。
