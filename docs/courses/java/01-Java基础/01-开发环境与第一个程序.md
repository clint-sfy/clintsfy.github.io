# 开发环境与第一个 Java 程序

## 学习目标

- 区分 JDK、JRE、JVM 和 `java`、`javac`、`jar` 等命令。
- 能在命令行创建、编译、运行带包名的程序，并理解 classpath。
- 学会用 IDE 调试程序，同时保留命令行复现能力。

## 核心知识点

JDK 提供编译器、标准库和诊断工具，JVM 负责加载并执行字节码。推荐设置 `JAVA_HOME`，把 `bin` 加入 PATH；用 `java --version` 和 `javac --version` 检查版本。源码文件名通常与 public 类名一致，包名与目录层级对应。编译时 `javac -d out src/com/example/Main.java`，运行时用 `java -cp out com.example.Main`。模块化项目还会使用 `--module-path`。

## 实践任务

创建 `com.example.Main`，打印 JDK 版本、当前工作目录和一段问候语；再故意把类文件放到错误目录，观察包名与 classpath 不匹配时的错误。使用 IDE 设置断点，单步观察局部变量，并记录命令行等价操作。

## 易错点

- 把 JDK 安装目录和项目目录混为一谈，或只配置 IDE 而没有配置命令行环境。
- 用 `java Main` 运行带包名的类；运行参数应使用完全限定类名。
- 把源代码版本、编译目标版本和运行时版本混在一起，导致 `UnsupportedClassVersionError`。

## 复习清单

- [ ] 能解释 JDK、JVM、字节码三者的关系。
- [ ] 能独立完成源码、编译输出目录、classpath 的配置。
- [ ] 能读懂找不到类、找不到主方法、版本不兼容三类错误。
