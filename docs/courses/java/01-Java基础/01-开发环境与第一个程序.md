# 开发环境与第一个 Java 程序

## 学习目标

- 区分 JDK、JRE、JVM 和 `java`、`javac`、`jar` 等命令。
- 能在命令行创建、编译、运行带包名的程序，并理解 classpath。
- 学会用 IDE 调试程序，同时保留命令行复现能力。

## 核心知识点

### JDK、JRE 与 JVM

| 名称 | 用途 | 主要内容 |
| --- | --- | --- |
| JVM | 执行 Java 字节码 | 类加载器、执行引擎、内存管理、垃圾回收 |
| JRE | 提供运行环境 | JVM 与运行程序需要的标准类库 |
| JDK | 提供完整开发环境 | JRE 能力、编译器、打包与诊断工具 |

JDK 20 是本笔记使用的版本。它不是 LTS 版本，但适合按指定版本学习 Java 语法。常用工具包括：

- `java`：启动 JVM，运行类、JAR 或单文件源码。
- `javac`：把 `.java` 源码编译为 `.class` 字节码。
- `jar`：创建和查看 JAR 包。
- `javadoc`：从文档注释生成 API 文档。
- `jshell`：交互式验证 Java 表达式和小段代码。
- `javap`：查看类结构或反汇编字节码。

### 安装与检查 JDK 20

安装完成后，`JAVA_HOME` 应指向 JDK 根目录，`PATH` 中加入 `%JAVA_HOME%\bin`。检查版本：

```powershell
java --version
javac --version
```

两个命令都应显示 `20`。如果 `java` 与 `javac` 来自不同目录，可用 `Get-Command java` 和 `Get-Command javac` 检查实际路径。

### 第一个程序

```java
public class HelloJava {
    public static void main(String[] args) {
        System.out.println("Hello, Java 20!");
        System.out.println("当前版本：" + System.getProperty("java.version"));
    }
}
```

```powershell
javac HelloJava.java
java HelloJava
```

`public class HelloJava` 必须保存在 `HelloJava.java`。`main` 是控制台程序入口：`public` 让 JVM 能访问它，`static` 表示无需创建对象，`void` 表示没有返回值，`String[] args` 保存命令行参数。

### 从源码到运行结果

```text
HelloJava.java --javac--> HelloJava.class --JVM--> 当前平台机器指令
```

`.class` 保存平台无关字节码。JVM 会加载、校验并解释或即时编译字节码，所以同一份字节码可在安装了兼容 JVM 的不同系统上运行。查看字节码：

```powershell
javap -c HelloJava
```

JDK 11 起也可直接运行单文件：`java HelloJava.java`。这适合小示例，正式项目仍应理解编译产物。

### 包、目录与 classpath

```java
package com.clint.learn;

public class Main {
    public static void main(String[] args) {
        System.out.println("package demo");
    }
}
```

文件放在 `src/com/clint/learn/Main.java`：

```powershell
javac -d out src/com/clint/learn/Main.java
java -cp out com.clint.learn.Main
```

`-d out` 指定编译输出目录，`-cp out` 把 `out` 设为查找类的根目录。运行带包名的类必须写完全限定名，不能只写 `Main`。

### 常见运行错误

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 找不到 `javac` | 未安装 JDK 或 PATH 错误 | 检查 JDK 20 的 `bin` |
| 找不到或无法加载主类 | 包名、类名或 classpath 错误 | 从 classpath 根目录运行完全限定名 |
| 找不到 main 方法 | 入口签名写错 | 使用标准 `main` 签名 |
| `UnsupportedClassVersionError` | 编译 JDK 高于运行 JDK | 统一为 JDK 20 或降低目标版本 |

## 易错点

- 把 JDK 安装目录和项目目录混为一谈，或只配置 IDE 而没有配置命令行环境。
- 用 `java Main` 运行带包名的类；运行参数应使用完全限定类名。
- 把源代码版本、编译目标版本和运行时版本混在一起，导致 `UnsupportedClassVersionError`。

## 本节小结

JDK 提供开发工具，JVM 负责执行字节码。Java 的基本开发闭环是编写 `.java`、使用 `javac` 编译、使用 `java` 运行。包名决定类的完整名称，classpath 决定 JVM 从哪里查找类。
