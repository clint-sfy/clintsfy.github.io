# 基础语法与程序结构

## 学习目标

- 读写类、方法、变量声明和表达式组成的 Java 程序。
- 理解静态方法、实例方法、参数传递和局部变量作用域。
- 使用注释、命名约定和格式化工具写出可维护代码。

## 核心知识点

Java 语句以分号结束，代码块用大括号形成作用域。标识符区分大小写，类名通常使用 PascalCase，方法和变量使用 camelCase，常量使用全大写加下划线。方法由返回类型、名称、参数列表和方法体组成；Java 只有按值传递，传递对象变量时复制的是引用值。重载要求参数列表不同，不能只靠返回值区分。表达式按优先级求值，复杂表达式应拆成命名变量。

## 实践任务

编写一个“成绩单”类：提供计算平均分、判断及格和格式化输出三个方法；分别写静态工具方法与实例方法，再为边界输入（空数组、负分、超过满分）明确行为。使用格式化工具统一缩进并补充 Javadoc。

## 易错点

- 误以为对象参数是“引用传递”，从而错误预期方法会替换调用方变量。
- 局部变量没有默认值，声明后必须先赋值才能读取。
- 在重载中使用自动拆箱、可变参数导致调用二义性。
- 忽略 `String` 的不可变性，把 `==` 当作字符串内容比较。
