# 基础语法与程序结构

## 学习目标

- 读写类、方法、变量声明和表达式组成的 Java 程序。
- 理解静态方法、实例方法、参数传递和局部变量作用域。
- 使用注释、命名约定和格式化工具写出可维护代码。

## 核心知识点

### 程序结构

```java
package com.clint.demo;

import java.util.Scanner;

public class Main {
    private static final String APP_NAME = "Java Notes";

    public static void main(String[] args) {
        System.out.println(APP_NAME);
    }
}
```

包声明位于非注释代码第一行，`import` 用于引用其他包中的类型，类是 Java 代码的基本组织单位。Java 区分大小写，语句通常以分号结束，花括号形成作用域。

### 标识符与命名

标识符由字母、数字、下划线或 `$` 组成，不能以数字开头，也不能使用关键字。常用约定：

- 类、接口、枚举：`PascalCase`，如 `StudentService`。
- 方法、变量：`camelCase`，如 `calculateTotal`。
- 常量：大写下划线，如 `MAX_RETRY_COUNT`。
- 包名：全小写，如 `com.clint.notes`。

### 变量、常量与作用域

```java
public class VariableDemo {
    static int field;                 // 字段默认值为 0
    static final int MAX_SIZE = 100;  // 常量只能赋值一次

    public static void main(String[] args) {
        int count = 1;                // 局部变量必须先赋值
        var message = "hello";       // 推断为 String
        System.out.println(message + count + field);
    }
}
```

字段有默认值，局部变量没有可读取的默认值。`final` 引用不能再指向别的对象，但对象本身未必不可变。`var` 只能推断局部变量类型，不能用于字段、方法参数，也不能根据 `null` 推断类型。

### 控制台输入输出

```java
import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        try (Scanner scanner = new Scanner(System.in)) {
            System.out.print("姓名：");
            String name = scanner.nextLine();
            System.out.print("年龄：");
            int age = Integer.parseInt(scanner.nextLine());
            System.out.printf("%s 明年 %d 岁%n", name, age + 1);
        }
    }
}
```

`print` 不换行，`println` 自动换行，`printf` 支持 `%s`、`%d`、`%.2f`、`%n` 等格式。输入时统一使用 `nextLine()` 再转换类型，可避免 `nextInt()` 遗留换行符。

### 方法定义

```java
static double average(int first, int second) {
    return (first + second) / 2.0;
}

static void printResult(double value) {
    System.out.printf("平均值：%.2f%n", value);
}
```

方法由修饰符、返回类型、名称、参数列表和方法体组成。`void` 表示不返回值，`static` 方法属于类，实例方法属于对象。

### Java 只有按值传递

```java
static void changeNumber(int value) {
    value = 99;                 // 不影响调用方变量
}

static void changeArray(int[] values) {
    values[0] = 99;             // 修改共同指向的数组内容
    values = new int[]{1, 2};   // 只替换方法内部复制的引用
}
```

传入基本类型时复制数值；传入对象时复制“引用这个值”。因此方法能修改同一个对象的内容，但不能替换调用方保存的引用。

### 方法重载

```java
static int max(int a, int b) { return a > b ? a : b; }
static double max(double a, double b) { return a > b ? a : b; }
```

同名方法的参数数量、类型或顺序必须不同；只改变返回类型不能构成重载。

## 易错点

- 误以为对象参数是“引用传递”，从而错误预期方法会替换调用方变量。
- 局部变量没有默认值，声明后必须先赋值才能读取。
- 在重载中使用自动拆箱、可变参数导致调用二义性。
- 忽略 `String` 的不可变性，把 `==` 当作字符串内容比较。

## 本节小结

Java 代码以类组织，以方法封装行为。变量作用域由代码块决定，字段和局部变量的初始化规则不同。方法参数始终按值传递，重载由参数列表而不是返回值决定。
