# 基础语法与程序结构

## 学习目标

- 认识类、包、`import`、标识符、变量、常量和作用域。
- 掌握 `var`、标准输入输出、静态方法与实例方法的使用边界。
- 通过参数和重载案例理解 Java 的按值传递。

## 核心知识点

### 专业术语

- **类（class）**：声明字段、构造器和方法的类型；一个源文件可以包含多个类型，但最多一个 `public` 顶层类。
- **包（package）与 import**：包组织命名空间，`import` 只为源码提供简写，不会把对象复制进当前类。
- **标识符（identifier）**：变量、方法和类型的名称，必须遵守 Java 的命名规则且不能使用关键字。
- **作用域（scope）**：名称可被引用的代码区域；局部变量、参数、实例字段和静态字段的生命周期与可见范围不同。
- **按值传递（pass-by-value）**：方法收到的是实参值的副本；引用类型传递的是“引用值”的副本。

### 白话解释与边界

变量像带类型的标签，常量用 `final` 表示绑定后不能再次赋值；标签的作用域结束后就不能直接访问。`var` 仍然是静态类型，只能用于有初始化表达式的局部变量，不能用在字段、方法参数或返回类型。`System.out.println` 负责输出，`Scanner` 能读取输入，但输入格式错误会抛出异常，边界应由调用方处理。

Java 的方法参数没有“按引用传递”这一模式：传入基本类型时复制数值，传入对象时复制引用值，因此方法可以修改对象内部状态，却不能让调用方变量改为指向另一个对象。重载要求参数列表不同，不能只靠返回类型区分。

## 简单案例

下面的例子同时展示静态方法、实例方法、重载和引用值副本：

```java
import java.util.Scanner;

public class SyntaxDemo {
    static int twice(int value) {
        return value * 2;
    }

    static String twice(String value) { // 重载：参数类型不同
        return value + value;
    }

    static void changeNumber(int value) {
        value = 99;
    }

    static void addMark(StringBuilder text) {
        text.append("!");
    }

    String label(String name) { // 实例方法需要对象来调用
        return "Hello, " + name;
    }

    public static void main(String[] args) {
        final int limit = 3;
        int count = 2;
        StringBuilder message = new StringBuilder("Java");
        changeNumber(count);
        addMark(message);
        try (Scanner scanner = new Scanner("Ada")) {
            String name = scanner.nextLine();
            System.out.println(new SyntaxDemo().label(name));
        }
        System.out.println(twice(count) + ", " + twice("go"));
        System.out.println("count=" + count + ", message=" + message + ", limit=" + limit);
    }
}
```

输出为 `Hello, Ada`、`4, gogo` 和 `count=2, message=Java!, limit=3`。`changeNumber` 只改了参数副本；`addMark` 通过复制的引用值访问同一个 `StringBuilder` 对象，所以调用方能看到对象状态变化。

## 易混点

- `var` 是编译器推断出的静态类型，不是运行时动态类型，也不能省略初始化。
- `import` 只改变源码中的书写方式，不改变包名、对象身份或 classpath。
- Java 是按值传递；对象参数的值恰好是引用，不能据此把 Java 说成按引用传递。
- 重载看编译期参数列表，重写看继承关系和运行时分派；仅改变返回类型不构成重载。

## 课后小问

1. 为什么 `changeNumber(count)` 返回后 `count` 仍然是 2？
答案：方法接收的是基本类型数值的副本，方法内把副本改成 99 不会改动调用方变量。
解析：实参与形参是两个变量；引用类型也按值传递，只是复制的值是引用，所以才可能通过它修改同一对象。

2. `var` 能不能作为字段类型或方法参数类型？
答案：不能，`var` 只用于有初始化表达式的局部变量和传统 for 循环变量。
解析：字段和方法签名需要稳定、可被调用者看到的类型；局部 `var` 仍在编译期确定类型，并没有引入动态类型系统。

## 本节小结

- 类、包和 import 负责组织源码，标识符和作用域决定名称在哪里可见。
- `final` 约束重新赋值，`var` 只是局部变量的类型推断写法。
- 静态方法属于类，实例方法通过对象状态工作，输入输出 API 还要处理格式边界。
- Java 所有参数都按值传递，重载由参数列表区分而不是由返回类型区分。
