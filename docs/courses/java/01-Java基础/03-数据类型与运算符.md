# 数据类型与运算符

## 学习目标

- 能按数据规模、精度和是否可为空选择类型。
- 能预判转换、装箱和表达式计算后的类型及风险。
- 能安全使用数值、逻辑、位、条件与字符串比较运算。

## 基本类型与引用类型

Java 有八种基本类型。它们直接保存数值或布尔状态，不是对象；相应包装类（如 `Integer`）才是对象。字段（类中、方法外的变量）会自动得到下表的默认值；**局部变量绝不会自动初始化**，读取前必须赋值。

| 类型 | 位数与范围/特性 | 字面量与默认值 | 包装类与常见场景 |
| --- | --- | --- | --- |
| `byte` | 8 位，-128～127 | `byte b = 12;`；默认 `0` | `Byte`；二进制协议、原始字节数据 |
| `short` | 16 位，-32,768～32,767 | `short s = 1000;`；默认 `0` | `Short`；少见，紧凑存储 |
| `int` | 32 位，约 ±21 亿 | `int n = 42;`；默认 `0` | `Integer`；普通计数、数组下标，整数首选 |
| `long` | 64 位，约 ±9.22×10¹⁸ | `long id = 9_000_000_000L;`；默认 `0L` | `Long`；时间戳、文件大小、较大 ID |
| `float` | 32 位浮点，约 6～7 位有效数字 | `float f = 1.5F;`；默认 `0.0F` | `Float`；内存敏感的近似测量，通常优先 `double` |
| `double` | 64 位浮点，约 15～16 位有效数字 | `double d = 3.14;`；默认 `0.0D` | `Double`；科学计算、一般近似小数 |
| `char` | 16 位无符号 UTF-16 代码单元，0～65,535 | `char c = '中';`；默认 `\u0000` | `Character`；单个 UTF-16 单元、字符分类 |
| `boolean` | 逻辑真/假；JVM 内部表示不应依赖 | `boolean ok = true;`；默认 `false` | `Boolean`；开关、条件状态 |

引用类型包括类、接口、数组、枚举、记录和 `String`。变量保存的是对象引用，可以为 `null`；对 `null` 调用方法、访问字段或自动拆箱会抛 `NullPointerException`。不要把 `null` 当成“空字符串”或数字 0。

```java
public class TypeDefaultsDemo {
    static int fieldCount;       // 字段：默认 0
    static boolean fieldReady;   // 字段：默认 false
    static String fieldName;     // 引用字段：默认 null

    public static void main(String[] args) {
        int localCount = 1;      // 局部变量必须明确赋值
        System.out.println(fieldCount + "," + fieldReady + "," + fieldName);
        System.out.println(localCount);
    }
}
```

## 整数字面量、转换与溢出

十进制是默认写法，也可用 `0b` 写二进制、`0` 写八进制、`0x` 写十六进制。下划线只为提高可读性，不能放在前后缀、开头或结尾，例如 `1_000_000`、`0b1010_0101` 合法。整数常量默认是 `int`，超出 `int` 或想明确为 `long` 时加 `L`（推荐大写）。

扩大转换通常安全：`byte → short → int → long → float → double`；但 `long` 到 `float` 也可能失去精度。窄化转换必须显式写强制转换，可能截断小数或发生环绕溢出。`byte`、`short`、`char` 参与 `+ - * /` 时会先提升为 `int`。

```java
public class NumberConversionDemo {
    public static void main(String[] args) {
        int binary = 0b1010_0101;
        int hex = 0xFF;
        long visitors = 3_000_000_000L;
        byte left = 100, right = 30;
        int sum = left + right;           // 先提升为 int
        byte wrapped = (byte) (left + right); // 130 变为 -126
        int max = Integer.MAX_VALUE;

        System.out.println(binary + "," + hex + "," + visitors);
        System.out.println(sum + "," + wrapped);
        System.out.println(max + 1);      // int 溢出：变为负数
    }
}
```

需要在溢出时立即失败，可用 `Math.addExact`、`Math.multiplyExact`；需要先检查外部文本，使用 `Integer.parseInt` 并处理 `NumberFormatException`。强制转换不是校验：`(int) 3.9` 的结果是 `3`，不是四舍五入。

## 浮点、精确小数与字符

`float`、`double` 使用二进制浮点表示，许多十进制小数无法精确存储，因此不要用 `==` 判断计算结果是否“相等”。近似比较可设定容差；货币、税率等要求十进制精确规则的业务应使用 `BigDecimal`。构造 `BigDecimal` 时优先用字符串或 `BigDecimal.valueOf`，不要传入 `new BigDecimal(0.1)`。

```java
import java.math.BigDecimal;

public class DecimalDemo {
    public static void main(String[] args) {
        double total = 0.1 + 0.2;
        System.out.println(total);                    // 可能显示 0.30000000000000004
        System.out.println(Math.abs(total - 0.3) < 1e-9);

        BigDecimal price = new BigDecimal("0.10");
        BigDecimal quantity = BigDecimal.valueOf(3);
        System.out.println(price.multiply(quantity)); // 0.30
    }
}
```

`char` 代表一个 UTF-16 代码单元，不一定代表用户看见的一个“字符”。BMP（基本多文种平面）中的 `char` 可直接转换为数值；补充平面的字符（如 😀）由一对代理项构成，应以 Unicode 码点处理，并遍历 `String.codePoints()`。

```java
public class UnicodeDemo {
    public static void main(String[] args) {
        char letter = 'A';
        System.out.println((int) letter);             // 65
        String emoji = "😀";
        System.out.println(emoji.length());           // 2 个 UTF-16 代码单元
        System.out.println(emoji.codePointCount(0, emoji.length())); // 1 个码点
        emoji.codePoints().forEach(System.out::println);
    }
}
```

## 包装、装箱与字符串比较

泛型集合不能放基本类型，所以使用包装类：`List<Integer>`。自动装箱把 `int` 变为 `Integer`，自动拆箱则反过来。拆箱 `null` 会抛异常，边界数据应先判空或给明确默认策略。`Integer` 等包装类会缓存一部分常用值（`Integer` 至少缓存 -128 到 127），所以 `==` 比较包装对象的结果可能随数值变化；比较数值用 `equals` 或先安全拆箱。

```java
public class BoxAndStringDemo {
    public static void main(String[] args) {
        Integer a = 100;
        Integer b = 100;
        Integer c = 200;
        Integer d = 200;
        System.out.println(a == b);        // true，但不能依赖
        System.out.println(c.equals(d));   // true：比较数值

        Integer nullable = null;
        int safe = nullable == null ? 0 : nullable; // 避免拆箱 NPE
        String first = new String("java");
        String second = "java";
        System.out.println(first == second);         // false：比较引用
        System.out.println(first.equals(second));    // true：比较内容
        System.out.println(safe);
    }
}
```

`String` 是不可变对象；`==` 问“是否同一个对象”，`equals` 问“字符内容是否相同”。当左侧可能为 `null` 时，用常量调用：`"admin".equals(role)`，结果安全地为 `false`。

## 常用运算符

| 类别 | 运算符 | 用法与注意点 |
| --- | --- | --- |
| 算术 | `+ - * / % ++ --` | 整数除法丢弃小数；`%` 常用于奇偶、循环下标；`++` 有副作用，不要塞进复杂表达式。`+` 也拼接字符串。 |
| 比较 | `== != > >= < <=` | 结果是 `boolean`；对象通常用 `equals` 比较内容。 |
| 逻辑 | `! && ||` | `&&`、`||` 短路，适合先判空再访问；`&`、`|` 用于布尔值时不短路。 |
| 位与移位 | `& | ^ ~ << >> >>>` | 用于位掩码、协议和底层数据；`>>` 保留符号位，`>>>` 左侧补 0。 |
| 赋值 | `= += -= *= /= %= &= |= ^= <<= >>= >>>=` | 复合赋值会隐含窄化，例如 `byte x = 1; x += 200;` 可编译。 |
| 条件 | `条件 ? 值1 : 值2` | 二选一表达式；简单选择清晰，复杂分支写 `if/else`。 |

```java
public class OperatorDemo {
    public static void main(String[] args) {
        int permissions = 0b0101;
        int write = 0b0010;
        boolean canWrite = (permissions & write) != 0;
        int shifted = -8 >> 1;
        int unsignedShifted = -8 >>> 1;
        String name = null;
        boolean hasName = name != null && !name.isBlank();
        int level = canWrite ? 2 : 1;

        System.out.println(canWrite + "," + shifted + "," + unsignedShifted);
        System.out.println(hasName + "," + level);
    }
}
```

常见优先级可记为：后缀 `++` → 一元 `!`/强转 → 算术 `* / %`、`+ -` → 移位 → 比较 → 相等 → 位运算 → `&&` → `||` → 三元 → 赋值。记不准或表达式包含多种运算符时，加括号比背表更可靠；不要依赖副作用和优先级来压缩代码。

## 易错点

- 把 `long` 字面量遗漏 `L`，或以为 `(byte) 130` 会报错；窄化转换会静默截断或环绕。
- 把字段默认值误用于局部变量；局部变量未初始化不能编译。
- 用 `double` 直接计算和比较金额，或用 `new BigDecimal(double)` 把已有误差带入精确计算。
- 把 `char` 当成完整 Unicode 字符，导致表情和少数文字的长度、截取处理错误。
- 用 `==` 比较 `String`、`Integer` 等对象，或让可空包装类自动拆箱。
- 把 `&`、`|` 当作 `&&`、`||` 使用，导致右侧本应跳过的空引用访问仍会执行。

## 本节小结

`int` 是普通整数首选，`long` 处理更大整数，`double` 处理可接受误差的近似值，`BigDecimal` 处理十进制精确业务。基本类型直接保存值，引用类型可为 `null`；包装类是集合和泛型的桥梁，但要防拆箱空指针和缓存陷阱。表达式会发生数值提升，强制转换和浮点计算都可能丢失信息；对象内容比较应使用 `equals`。
