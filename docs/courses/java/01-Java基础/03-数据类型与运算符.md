# 数据类型与运算符

## 学习目标

- 区分八种基本类型与引用类型，理解取值范围和默认值。
- 掌握数值提升、显式转换、装箱拆箱和 `null` 的风险。
- 正确使用算术、比较、逻辑、位运算、条件和赋值运算符。

## 核心知识点

基本类型包括 `byte/short/int/long/float/double/char/boolean`；整数运算默认提升到 `int`，金额等精确场景使用 `BigDecimal`。窄化转换可能溢出，浮点数不宜直接用 `==` 比较。包装类型用于泛型和集合，自动拆箱遇到 `null` 会抛 `NullPointerException`。短路逻辑 `&&`、`||` 可以避免无效访问；位移操作要注意符号位和移位距离。文本拼接优先使用 `StringBuilder` 或格式化 API。

## 实践任务

实现一个温度和金额转换器：覆盖摄氏/华氏转换、四舍五入、非法输入和大额金额；分别用 `double`、`BigDecimal` 计算，比较结果差异并写下选择依据。增加位掩码代码表示用户权限。

## 易错点

- `0.1 + 0.2` 不一定等于 `0.3`；金额计算不能直接依赖二进制浮点。
- `char` 是无符号 UTF-16 code unit，不等同于完整 Unicode 码点。
- `byte + byte` 的结果是 `int`，赋回 `byte` 需要显式转换。
- `Integer` 的 `==` 可能受缓存影响，值比较应使用 `equals`。
