# 泛型与类型安全

## 学习目标

- 定义泛型类、泛型接口和泛型方法，减少强制类型转换。
- 理解 `extends`、`super`、PECS 和通配符捕获。
- 知道类型擦除、原始类型和不可具体化类型带来的限制。

## 核心知识点

泛型约束在编译期生效，运行时大多经过类型擦除；`List<Integer>` 不是 `List<Number>` 的子类型。生产者使用 `? extends T`，消费者使用 `? super T`；同时读写时使用具体类型参数。类型参数可以有上界，如 `<T extends Comparable<T>>`。不能直接创建 `new T[]` 或对参数化类型使用普通数组，反射和 varargs 需要额外的堆污染防护。

## 实践任务

实现一个泛型 `Page<T>` 和 `Repository<T, ID>`：分页结果不可变，查询方法分别接收生产者和消费者；开启编译器的 unchecked 警告，把每一处抑制范围缩到最小。

## 易错点

- 误以为泛型参数在运行时保留，尝试 `instanceof List<String>`。
- 使用原始类型绕过检查，运行时才遇到 `ClassCastException`。
- 把 `List<? extends Number>` 当作可添加任意 Number 的列表。
- 用泛型数组或可变参数返回内部数组，造成堆污染。

## 复习清单

- [ ] 能用 PECS 解释 extends 和 super。
- [ ] 能指出类型擦除造成的两个限制。
- [ ] 能写一个没有不必要 unchecked 警告的泛型 API。
