# 集合框架与数据结构

## 学习目标

- 区分 List、Set、Queue/Deque 和不可变集合的语义。
- 理解 ArrayList、LinkedList、ArrayDeque、HashSet、TreeSet 的实现取舍。
- 正确迭代、删除、排序并估算时间和空间复杂度。

## 核心知识点

List 保持顺序并允许重复；Set 强调唯一性；Queue/Deque 表达先进先出或双端操作。ArrayList 随机访问快、尾部追加均摊常数；LinkedList 不等于高性能，节点和缓存开销常使它不如数组结构。HashSet 依赖 equals/hashCode，TreeSet 依赖排序关系。使用 `List.of`、`Set.of` 创建不可变集合，需提前确认是否需要修改。迭代器删除是安全方式之一。

## 实践任务

实现排行榜：用 List 保留展示顺序，用 Set 去重用户，用 PriorityQueue 获取前 K 名；为 1 千、1 万、100 万条数据记录耗时和内存趋势，并解释选择。

## 易错点

- 修改集合元素参与哈希的字段后，HashSet/HashMap 可能无法找到元素。
- 迭代增强 for 时直接结构性修改，触发并发修改异常。
- 把 `Arrays.asList`、`List.of` 得到的固定/不可变集合当作可变列表。
- 只看 Big-O，忽略装箱、内存局部性和容量扩张。
