# 数组与多维数组

## 学习目标

- 创建、遍历、复制和排序一维数组与二维数组。
- 理解数组长度固定、索引从零开始和引用语义。
- 能在数组与集合之间做明确转换。

## 核心知识点

数组是对象，`length` 是固定属性；创建后基本类型元素会初始化为零，引用元素初始化为 `null`。二维数组本质是数组的数组，行长度可以不同。使用 `Arrays.equals/deepEquals` 比较内容，`copyOf` 与 `System.arraycopy` 复制数据，`sort` 完成排序。数组越界由运行时抛出异常。需要动态长度时使用 `ArrayList`，不要反复创建数组模拟扩容。

## 实践任务

实现成绩统计：读取二维数组表示多位学生的多科成绩，计算每人平均分、每科最高分和总排名；增加空行、不等长行和越界索引测试，并比较手写排序和 `Arrays.sort`。

## 易错点

- 复制数组变量只复制引用，修改副本仍会影响原数组。
- `Arrays.asList(primitiveArray)` 不会得到基本类型元素列表。
- 用 `array.length` 调用方法或把二维数组当成连续矩阵。
- 排序后丢失原始顺序，却没有先复制数组。
