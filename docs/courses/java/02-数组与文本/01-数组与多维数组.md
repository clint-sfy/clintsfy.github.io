# 数组与多维数组

## 学习目标

- 创建、遍历、统计和复制一维数组与二维数组。
- 理解数组对象、固定长度、索引边界和引用语义。
- 使用 `Arrays` 工具，并能在数组与集合之间做有依据的选择。

## 核心知识点

### 专业术语

- **数组（array）**：长度固定、元素类型相同的对象；长度通过 `array.length` 读取而不是方法调用。
- **索引（index）**：从 0 到 `length - 1` 的位置编号，越界会抛出 `ArrayIndexOutOfBoundsException`。
- **二维数组**：数组的元素仍然是数组，因此本质是“数组的数组”，每一行可以有不同长度。
- **浅复制与内容复制**：复制外层引用得到浅复制；`Arrays.copyOf`、`System.arraycopy` 能复制元素内容，但嵌套引用仍需逐层复制。
- **`Arrays` 工具类**：提供 `sort`、`copyOf`、`equals`、`deepEquals` 等常用数组操作。

### 白话解释与边界

数组对象创建后长度不能改变；需要扩容时，通常创建更大数组并复制，或者直接使用 `ArrayList`。基本类型数组复制的是值，引用类型数组复制的是引用，所以复制后的两个数组可能仍共享同一个可变元素。二维数组不是一块必须等宽的矩形内存，访问 `rows[i][j]` 时既要验证行索引，也要验证该行自己的长度。

数组适合长度已知、按索引访问频繁且内存布局简单的场景；集合更适合增删、查重或表达动态数量。`Arrays.asList` 的可变参数在传入 `new int[]{1, 2}` 时会把整个原始类型数组当成一个元素，得到大小为 1 的 `List<int[]>`；它不会把每个 `int` 自动装箱成 `List<Integer>`。需要整数列表时应显式遍历装箱或使用 `Arrays.stream(intArray).boxed()`。

## 常用 API 速查

### 创建、访问与遍历

| 目标 | 高频写法 | 说明 |
| --- | --- | --- |
| 创建并填充 | `int[] a = {1, 2, 3};` | 字面量只能在声明处直接使用；其他位置写 `new int[]{1, 2, 3}`。 |
| 创建指定长度 | `int[] a = new int[3];` | 基本类型元素默认是 `0`，引用类型元素默认是 `null`。 |
| 访问与长度 | `a[i]`、`a.length` | 索引从 0 开始；`length` 是属性，不是方法。 |
| 按索引遍历 | `for (int i = 0; i < a.length; i++)` | 需要索引或修改元素时使用。 |
| 遍历元素 | `for (int value : a)` | 只读每个元素时更简洁，修改 `value` 不会改数组。 |

### `Arrays` 高频操作

| 任务 | 写法 | 关键边界 |
| --- | --- | --- |
| 打印 | `Arrays.toString(a)` | 多维数组用 `Arrays.deepToString(rows)`。 |
| 复制 | `Arrays.copyOf(a, newLength)` | 返回新数组；长度变长时用默认值补齐。 |
| 复制范围 | `Arrays.copyOfRange(a, from, to)` | `from` 包含、`to` 不包含；`to` 超过原长度会用默认值补齐。 |
| 指定位置复制 | `System.arraycopy(src, srcPos, dst, dstPos, length)` | 适合已知源/目标位置的批量复制；嵌套数组仍是浅复制。 |
| 排序 | `Arrays.sort(a)` | 排序后数组会被原地修改；范围重载同样使用左闭右开区间。 |
| 二分查找 | `Arrays.binarySearch(a, value)` | 必须先按同一规则排序；找到返回索引，未找到返回负的插入点编码。 |
| 填充 | `Arrays.fill(a, value)` | 可用 `Arrays.fill(a, from, to, value)` 只填充一段。 |
| 比较 | `Arrays.equals(a, b)` | 一维按元素比较；嵌套数组使用 `Arrays.deepEquals(a, b)`。 |

```java
int[] values = {7, 2, 9, 2};
int[] copy = Arrays.copyOf(values, values.length);
Arrays.sort(copy);
int index = Arrays.binarySearch(copy, 7); // 先排序，再查找
Arrays.fill(values, 0, 1, 99);           // 只改 values[0]
System.out.println(Arrays.toString(copy) + ", index=" + index);
// 输出：[2, 2, 7, 9], index=2
```

低频补充：`Arrays.mismatch` 返回首个不同位置，`Arrays.compare` 按字典序比较，`Arrays.parallelSort` 适合评估过收益的大数组并行排序。

### 数组转 `List`：视图与 primitive 坑

| 场景 | 写法 | 得到的结果 |
| --- | --- | --- |
| 引用类型数组转视图 | `List<String> view = Arrays.asList(names);` | 固定大小视图；允许 `set`，不允许 `add`/`remove`，数组与列表会互相看到元素替换。 |
| 得到可增删列表 | `List<String> list = new ArrayList<>(Arrays.asList(names));` | 复制元素引用后的可变 `ArrayList`；增删不会改变原数组长度。 |
| `int[]` 转整数列表 | `Arrays.stream(nums).boxed().collect(Collectors.toCollection(ArrayList::new))` | 显式装箱为可变 `List<Integer>`；不要把 `Arrays.asList(nums)` 当成整数列表。 |
| 小型不可变列表 | `List.of("a", "b")` | 不接受 `null`，不能结构性修改；需要可变列表时再复制。 |

```java
int[] nums = {1, 2, 3};
List<int[]> wrong = Arrays.asList(nums); // size == 1，唯一元素是整个 int[]
List<Integer> boxed = Arrays.stream(nums).boxed().collect(Collectors.toCollection(ArrayList::new));
```

不常用转换：`IntStream.of(nums).mapToObj(Integer::valueOf)` 也能完成装箱；需要不可变结果时可使用流的 `toList()`，需要后续增删则显式收集为 `ArrayList`。

## 简单案例

```java
import java.util.Arrays;

public class ArrayDemo {
    public static void main(String[] args) {
        int[] scores = {88, 76, 95, 82};
        int[] original = Arrays.copyOf(scores, scores.length);
        Arrays.sort(scores);
        int[][] groups = {{88, 76}, {95, 82, 91}}; // 行长度可以不同

        int total = 0;
        for (int score : original) {
            total += score;
        }
        int[][] shallow = Arrays.copyOf(groups, groups.length);
        shallow[0][0] = 0; // 内层数组仍与 groups[0] 共享

        System.out.println("sorted=" + Arrays.toString(scores));
        // 输出：sorted=[76, 82, 88, 95]
        System.out.println("average=" + (total / (double) original.length));
        // 输出：average=85.25
        System.out.println("rows=" + groups.length + ", secondRow=" + groups[1].length);
        // 输出：rows=2, secondRow=3
        System.out.println("shared=" + groups[0][0]);
        // 输出：shared=0
    }
}
```

这个案例把排序、平均值、二维数组行长度和浅复制共享边界放在一起观察；排序只改动 `scores`，而 `shallow` 与原二维数组共享内层行。

## 易混点

- `array.length` 是固定属性，不能写成 `array.length()`；数组越界属于运行时错误，不会静默返回空值。
- `Arrays.copyOf` 对一维基本类型数组是内容复制，对二维数组只复制第一层引用，不能自动完成深复制。
- `Arrays.equals` 比较一维元素，`Arrays.deepEquals` 才按嵌套数组内容比较；直接比较数组变量只比较身份。
- `Arrays.binarySearch` 只能用于已按同一规则排序的数组；未找到时的负数不是普通的 `-1`，而是编码后的插入位置。
- `Arrays.asList` 是固定大小视图，`new ArrayList<>(...)` 才能正常增删；原始类型数组还会触发“整个数组作为一个元素”的陷阱。
- 数组长度固定，集合容量可按需求增长；需要频繁插入、删除或去重时，`ArrayList`/`Set` 通常更合适。

## 课后小问

1. 为什么 `Arrays.copyOf(groups, groups.length)` 后修改一行会影响原数组？
答案：它只复制了外层数组的元素引用，两个二维数组仍指向同一批内层数组。
解析：这叫浅复制；若要互不影响，需要为每一行分别调用 `Arrays.copyOf` 或建立明确的深复制策略。

2. 不等长二维数组访问 `rows[1][2]` 前要检查什么？
答案：先检查 `rows` 和行索引有效，再检查 `rows[1].length > 2`，因为每行长度独立。
解析：二维数组是数组的数组，第二维不是统一矩阵宽度；忽略行长度会得到 `ArrayIndexOutOfBoundsException`。

## 本节小结

- 数组是长度固定的对象，索引从零开始，基本元素有默认值。
- 二维数组是数组的数组，行可以不等长，访问要分层校验边界。
- 一维复制可复制内容，嵌套引用复制后仍可能共享内层对象。
- `Arrays` 适合排序、比较和复制；动态数量与查重需求应考虑集合。
