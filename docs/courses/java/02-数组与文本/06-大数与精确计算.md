# 大数与精确计算

## 学习目标

- 根据范围和精度要求选择基本类型、`BigInteger` 或 `BigDecimal`。
- 使用 `BigInteger` 完成任意精度整数运算和比较。
- 使用 `BigDecimal` 从字符串构造金额，明确除法舍入和比较规则。
- 使用 `Math` 的检查、舍入和取整 API，识别普通运算的溢出边界。

## 核心知识点

### 专业术语

- **溢出（overflow）**：结果超出基本整数类型可表示范围，普通运算可能静默回绕。
- **任意精度整数（arbitrary-precision integer）**：`BigInteger` 按需要扩展存储，不受 `long` 范围限制。
- **十进制定点数（decimal fixed-point）**：`BigDecimal` 用无穷精度的十进制小数表达，适合金额和计量。
- **舍入模式（rounding mode）**：除法或缩放无法精确表示时，使用 `RoundingMode` 规定保留哪一侧。
- **数值相等与表示相等**：`BigDecimal("1.0")` 与 `BigDecimal("1.00")` 的 `compareTo` 相等，但 `equals` 可能不同。

### 白话解释与边界

普通 `int`/`long` 像固定大小的盒子，装不下时可能从最大值绕回最小值；`Math.addExact` 等 API 会在溢出时抛异常。`BigInteger` 像可扩大的整数纸带，适合订单号、计数器和密码学相关整数，但对象和计算成本更高。

`BigDecimal` 应从字符串、整数或 `valueOf` 构造，不要把二进制浮点近似直接带进金额。除不尽时必须指定舍入策略；金额比较通常用 `compareTo`，格式展示使用 `setScale` 和 `toPlainString`。它们都是不可变对象，每次运算都会返回新值。

## 常用用法

### `BigInteger.valueOf`/构造器：创建大整数

```java
import java.math.BigInteger;

BigInteger fromLong = BigInteger.valueOf(9_000_000_000L);
BigInteger fromText = new BigInteger("12345678901234567890");
System.out.println(fromLong.add(fromText));
// 输出：12345678910234567890
```

文本构造会检查进制和格式；不要为普通小整数无条件使用大数，先看范围、性能和接口类型。

### `BigInteger.add`/`subtract`/`multiply`：大整数四则运算

```java
import java.math.BigInteger;

BigInteger principal = new BigInteger("10000000000000000000");
BigInteger result = principal.multiply(BigInteger.valueOf(3)).subtract(BigInteger.ONE);
System.out.println(result);
// 输出：29999999999999999999
```

运算不会修改原对象；链式表达式返回新值，适合超过 `long` 的精确整数计算。

### `BigInteger.divide`/`remainder`：整数商和余数

```java
import java.math.BigInteger;

BigInteger[] parts = new BigInteger("17").divideAndRemainder(BigInteger.valueOf(5));
System.out.println(parts[0] + ", " + parts[1]);
// 输出：3, 2
```

整数除法向零截断，除数为零会抛 `ArithmeticException`；需要同时得到商和余数时用 `divideAndRemainder`。

### `BigInteger.compareTo`/`signum`：比较大小和符号

```java
import java.math.BigInteger;

BigInteger amount = new BigInteger("-20");
System.out.println(amount.signum() + ", " + (amount.compareTo(BigInteger.ZERO) < 0));
// 输出：-1, true
```

`compareTo` 返回负数、零或正数，不要把返回值当成固定的 `-1`、`0`、`1`；`signum` 只表达符号。

### `BigInteger.pow`/`gcd`：幂和最大公约数

```java
import java.math.BigInteger;

BigInteger value = BigInteger.valueOf(12);
System.out.println(value.pow(2) + ", " + value.gcd(BigInteger.valueOf(18)));
// 输出：144, 6
```

指数必须是非负整数；大指数可能产生很大的对象，调用前要限制输入范围。

### `BigDecimal.valueOf`/字符串构造：创建精确小数

```java
import java.math.BigDecimal;

BigDecimal a = new BigDecimal("0.10");
BigDecimal b = BigDecimal.valueOf(0.20);
System.out.println(a.add(b));
// 输出：0.30
```

金额优先从字符串或 `valueOf(double)` 构造；`new BigDecimal(0.1)` 会把二进制浮点近似完整带入十进制结果。

### `BigDecimal.add`/`subtract`/`multiply`：精确小数运算

```java
import java.math.BigDecimal;

BigDecimal price = new BigDecimal("19.90");
BigDecimal quantity = new BigDecimal("3");
BigDecimal total = price.multiply(quantity).subtract(new BigDecimal("1.00"));
System.out.println(total);
// 输出：58.70
```

运算保留输入的 scale 规则，展示几位小数应在边界处明确 `setScale`；不要把 `toString` 的展示形式当成业务舍入策略。

### `BigDecimal.divide`：指定舍入模式除法

```java
import java.math.BigDecimal;
import java.math.RoundingMode;

BigDecimal average = new BigDecimal("10").divide(new BigDecimal("3"), 2, RoundingMode.HALF_UP);
System.out.println(average);
// 输出：3.33
```

除不尽且未指定舍入时可能抛 `ArithmeticException`；金额场景必须和业务约定小数位及舍入模式，不能默认 `HALF_UP` 永远正确。

### `BigDecimal.compareTo`：按数值比较

```java
import java.math.BigDecimal;

BigDecimal left = new BigDecimal("1.0");
BigDecimal right = new BigDecimal("1.00");
System.out.println(left.compareTo(right) == 0);
// 输出：true
```

金额和阈值比较通常使用 `compareTo`；`equals` 同时比较数值和 scale，可能把 `1.0` 与 `1.00` 判为不等。

### `setScale`/`RoundingMode`：固定小数位

```java
import java.math.BigDecimal;
import java.math.RoundingMode;

BigDecimal amount = new BigDecimal("12.345");
BigDecimal rounded = amount.setScale(2, RoundingMode.HALF_EVEN);
System.out.println(rounded);
// 输出：12.34
```

`setScale` 返回新对象；不同舍入模式在边界值上结果不同，应把模式写进领域规则或配置，而不是散落在调用处。

### `toPlainString`/`stripTrailingZeros`：输出小数

```java
import java.math.BigDecimal;

BigDecimal value = new BigDecimal("1000.00");
System.out.println(value.stripTrailingZeros().toPlainString());
// 输出：1000
```

`toPlainString` 避免科学计数法，适合协议和展示；去掉尾零前要确认调用方是否需要固定小数位。

### `Math.addExact`/`multiplyExact`：检查整数溢出

```java
public class MathExactDemo {
    public static void main(String[] args) {
        int total = Math.addExact(20, 22);
        int product = Math.multiplyExact(6, 7);
        System.out.println(total + ", " + product);
        // 输出：42, 42
    }
}
```

检查方法在结果超出类型范围时抛 `ArithmeticException`；适合不允许静默回绕的计数和索引计算。

### `Math.floorDiv`/`floorMod`：向下取整除法

```java
System.out.println(Math.floorDiv(-7, 3) + ", " + Math.floorMod(-7, 3));
// 输出：-3, 2
```

与整数 `/` 和 `%` 的向零截断不同，`floorDiv`/`floorMod` 适合按周期、页码或时间桶计算负数边界。

## 不常用但需要知道

### `BigInteger.mod`：非负模运算

```java
import java.math.BigInteger;

BigInteger remainder = new BigInteger("7").mod(BigInteger.valueOf(5));
System.out.println(remainder);
// 输出：2
```

被除数和模数都必须满足 `mod` 的非负约束，结果始终非负；如果需要保留被除数符号，比较 `remainder` 与 `remainder()` 的语义差异。

### `BigInteger.isProbablePrime`：概率素性判断

```java
import java.math.BigInteger;

boolean prime = BigInteger.valueOf(101).isProbablePrime(20);
System.out.println(prime);
// 输出：true
```

返回概率意义上的判断，`certainty` 越大误判概率越低；密码学用途应使用经过审计的库和协议，不能把它当成完整密钥生成方案。

### `BigInteger.probablePrime`：生成大素数

```java
import java.math.BigInteger;
import java.util.Random;

BigInteger prime = BigInteger.probablePrime(32, new Random(1));
System.out.println(prime.bitLength());
// 输出：32
```

示例使用普通 `Random` 仅为演示；安全密钥场景应使用 `SecureRandom`，并由密码学库管理参数和生命周期。

### `BigDecimal.divideAndRemainder`：同时取得商和余数

```java
import java.math.BigDecimal;

BigDecimal[] result = new BigDecimal("10.5").divideAndRemainder(new BigDecimal("3"));
System.out.println(result[0] + ", " + result[1]);
// 输出：3, 1.5
```

用于需要同时计算整数商和剩余量的分配逻辑；金额按份额分配还需要额外定义尾差归属。

### `Math.nextUp`/`nextDown`：访问相邻浮点值

```java
double value = 1.0;
System.out.println(Math.nextUp(value) > value);
// 输出：true
```

用于测试浮点边界或数值算法，不适合用来修补金额精度；金额仍优先使用 `BigDecimal`。

### `Math.round`/`ceil`/`floor`：浮点取整

```java
double value = 3.6;
System.out.println(Math.round(value) + ", " + Math.floor(value) + ", " + Math.ceil(value));
// 输出：4, 3.0, 4.0
```

这些方法处理的是二进制浮点数，返回类型和负数边界要看清；需要十进制舍入位数时使用 `BigDecimal.setScale`。

### `Math.random`：生成普通随机数

```java
double sample = Math.random();
System.out.println(sample >= 0.0 && sample < 1.0);
// 输出：true
```

适合简单模拟或演示，不能用于令牌、验证码、密钥和抽奖安全性；安全随机使用 `SecureRandom` 并定义可审计策略。

## 简单案例

```java
import java.math.BigDecimal;
import java.math.RoundingMode;

public class PreciseMoneyDemo {
    public static void main(String[] args) {
        BigDecimal price = new BigDecimal("19.90");
        BigDecimal count = new BigDecimal("3");
        BigDecimal discount = new BigDecimal("1.00");
        BigDecimal total = price.multiply(count).subtract(discount)
            .setScale(2, RoundingMode.HALF_UP);

        System.out.println("total=" + total.toPlainString());
        // 输出：total=58.70
        System.out.println("under60=" + (total.compareTo(new BigDecimal("60.00")) < 0));
        // 输出：under60=true
    }
}
```

案例把字符串构造、运算、舍入、格式化和比较串成金额边界流程；真实结算还要明确币种、税率、尾差、溢出上限和持久化 scale。

## 易混点

- `new BigDecimal(0.1)` 会保留二进制浮点误差，金额使用字符串或 `BigDecimal.valueOf`。
- `BigDecimal.equals` 比较 scale，金额数值比较通常用 `compareTo`；展示位数则另用 `setScale`。
- `BigDecimal.divide` 除不尽时必须指定精度和舍入，否则可能抛 `ArithmeticException`。
- `int`/`long` 普通运算可能静默溢出，`Math.addExact` 等检查 API 才会主动报错。
- `BigInteger`、`BigDecimal` 不可变，`add`、`multiply` 的返回值必须接住，不能期待原对象被修改。

## 课后小问

1. 为什么 `new BigDecimal("1.0").equals(new BigDecimal("1.00"))` 可能为 `false`，而 `compareTo` 为零？
答案：`equals` 同时比较数值和 scale，`compareTo` 只比较数值大小。
解析：金额阈值、排序和去重通常先确定业务是“数值相等”还是“格式也相等”，不要混用两个契约。

2. 为什么 `Math.addExact(Integer.MAX_VALUE, 1)` 比普通 `+` 更适合金额计数边界？
答案：`addExact` 在溢出时抛出 `ArithmeticException`，普通 `+` 可能静默回绕成负数。
解析：边界值一旦回绕，后续校验可能继续传播错误；若范围本身可能超过 `long`，应直接设计为 `BigInteger` 或 `BigDecimal`。

## 本节小结

- 需要超出基本类型范围的整数使用 `BigInteger`，需要十进制精度的金额使用 `BigDecimal`。
- 大数对象不可变，除法、舍入和比较必须把返回值和契约写清楚。
- `BigDecimal` 从字符串或 `valueOf` 构造，比较优先 `compareTo`，展示使用明确 scale。
- `Math` 的检查、取整和浮点边界 API 解决特定问题，不能替代金额建模和安全随机策略。

- 能使用 `Math.addExact`、`floorDiv` 等 API 处理边界计算。
