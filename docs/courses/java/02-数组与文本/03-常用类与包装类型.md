# 常用类与包装类型

## 学习目标

- 理解 Object 的 `equals`、`hashCode`、`toString` 契约。
- 正确使用包装类型、`BigInteger`、`BigDecimal`、`Math` 和 `Optional`。
- 通过标准库减少重复代码，同时明确 API 的异常和精度语义。

## 核心知识点

重写 `equals` 必须同时重写 `hashCode`；可变字段不宜参与哈希。包装类型服务于泛型，解析外部输入时使用 `parseInt` 等方法并处理格式异常。金额用 `BigDecimal` 的字符串构造器和明确舍入模式。Optional 用来表达“可能没有”的返回结果，不宜用于字段、序列化模型或所有参数。Math 的随机数、取整和溢出行为需要查清边界。

## 实践任务

为 `UserId` 编写不可变值对象：校验格式、实现 `equals/hashCode/toString`，并提供从字符串解析的方法；用 `Optional` 表达查询结果，用参数化测试覆盖空值、重复 ID 和非法格式。

## 易错点

- 只重写 `equals` 不重写 `hashCode`，导致 HashMap 查找失败。
- `new BigDecimal(0.1)` 把浮点误差带入精确计算。
- 把 Optional 当作对象字段或用 `get()` 代替明确的兜底策略。
- 忽略整数运算溢出；需要时使用 `Math.addExact` 等检查方法。
