# 线程基础与执行器

## 学习目标

- 区分 Runnable、Callable、Future 和线程生命周期。
- 使用 ExecutorService、ScheduledExecutorService 管理任务。
- 设计关闭、取消、超时和异常传播策略。

## 核心知识点

线程经历 NEW、RUNNABLE、BLOCKED、WAITING、TIMED_WAITING、TERMINATED 等状态。优先提交任务给执行器，而不是到处 new Thread；固定池适合受控 CPU 工作，缓存池和队列要有容量边界。Future 可获取结果、取消任务和等待超时；任务内部异常需要通过 Future 或 UncaughtExceptionHandler 观察。服务关闭时先停止接收、再等待、最后按策略中断。

## 实践任务

实现批量缩略图任务：固定线程池限制并行数，设置单任务和整体超时，收集成功/失败结果；测试关闭期间的新任务、取消响应和线程泄漏。

## 易错点

- 无界队列或无限创建线程导致内存耗尽。
- 调用 shutdown 后仍提交任务，忽略 RejectedExecutionException。
- 把 interrupt 当作强制杀线程，任务却不响应中断。
- 忘记关闭执行器，测试进程无法退出。
