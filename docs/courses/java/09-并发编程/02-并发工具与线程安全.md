# 并发工具与线程安全

## 学习目标

- 用 synchronized、ReentrantLock、ReadWriteLock 和 StampedLock 选择同步策略。
- 掌握 Atomic、LongAdder、CountDownLatch、CyclicBarrier、Semaphore、Phaser。
- 识别竞态、死锁、活锁、饥饿和阻塞队列问题。

## 核心知识点

线程安全来自不变性、线程隔离、消息传递或正确同步。synchronized 绑定对象监视器并自动释放，Lock 提供可中断、可超时和多个条件队列，但必须 finally unlock。原子类适合单变量 CAS 更新，LongAdder 适合高竞争统计。BlockingQueue 可实现生产者/消费者；锁顺序、超时和小临界区降低死锁风险。ConcurrentHashMap 只能保证自身操作安全，复合业务仍需设计原子边界。

## 实践任务

实现限流器：用 Semaphore 限制并发请求，用 ScheduledExecutorService 定期补充令牌；对比 synchronized 计数、AtomicInteger 和 LongAdder，在高竞争测试中记录吞吐和正确性。

## 易错点

- 忘记在异常路径释放 Lock，造成永久阻塞。
- 以为 volatile 能保证 `count++` 这种复合操作原子。
- 多把锁获取顺序不一致，形成死锁。
- 为了“线程安全”粗粒度锁住 I/O，吞吐骤降。
