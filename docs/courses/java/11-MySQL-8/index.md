# MySQL 8

本章使用 MySQL 8.0 与 InnoDB。先在本机准备独立的 `learning_lab` 实验库及有建库、建表权限的学习账号；不要在业务库执行实验。客户端与服务端是两个程序，安装客户端并不等于已经启动数据库服务。

按 [环境连接与数据库对象](./01-环境连接与数据库对象) → [表设计与 DDL](./02-表设计与DDL) → [数据类型、字符集与时区](./03-数据类型字符集与时区) → [数据写入、更新与删除](./04-数据写入更新与删除) 顺序阅读。第二篇建立 `users`、`orders` 两张基础表，后续示例复用它们；临时验证使用带 `lab_` 前缀的独立实验表。每段代码注明前置状态，重复执行前先检查对象是否存在。

后续学习依次是查询过滤与分页、连接与子查询、聚合与窗口函数、约束与索引、事务与锁、执行计划、[用户、权限、备份与恢复](./11-用户权限备份与恢复)，以及 [Java、JDBC 与 MyBatis 衔接](./12-Java-JDBC与MyBatis衔接)。本章共12篇，数据库语义以本章为事实源；写 Java 数据访问前，先掌握 SQL 和事务，再读 [JDBC](../12-工程实践/02-JDBC与事务) 与 [MyBatis](../14-后端工程/06-MyBatis核心与MyBatis-Plus重点)。

版本边界以服务端 `SELECT VERSION()` 为准，特别留意文中的 8.0 小版本要求。官方依据为 [MySQL 8.0 Reference Manual](https://dev.mysql.com/doc/refman/8.0/en/)。
