# 日期格式化与解析

## 学习目标

- 能用 `DateTimeFormatter` 在日期对象和文本之间稳定转换。
- 能为 `LocalDate`、`LocalTime` 和 `LocalDateTime` 选择合适的格式。
- 能处理 Locale、严格校验、可选字段和外部输入错误。

## 核心知识点

### 专业术语

- **解析（parse）**：把文本按格式转换成 `LocalDate`、`LocalTime` 或 `LocalDateTime`。
- **格式化（format）**：把日期时间对象按格式输出为文本。
- **`DateTimeFormatter`**：不可变且线程安全的格式化器，可以预定义、按模式或用构建器创建。
- **`uuuu` 与 `yyyy`**：`uuuu` 表示带正负号的年，更适合严格的日期时间 API；`yyyy` 是年-of-era 字段。

### 白话解释与边界

日期对象是结构化数据，字符串只是外部表示。解析时必须知道输入格式和地区规则，不能依赖机器默认格式；格式化时要区分“给用户看的本地化文本”和“给接口传输的稳定协议”。`DateTimeFormatter` 本身线程安全，可以缓存为常量。

模式字母有严格含义：`MM` 是月份、`mm` 是分钟，`HH` 是 24 小时制、`hh` 是 12 小时制。解析失败应在边界层捕获并返回清晰的输入错误，不要把格式异常吞掉后生成错误日期。

## 常用用法

### `LocalDate.parse`：将文本解析为日期

日期没有时分秒，适合生日、账期和截止日；输入不符合模式时会抛 `DateTimeParseException`。

```java
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;

DateTimeFormatter formatter = DateTimeFormatter.ofPattern("uuuu-MM-dd");
// 初始状态：formatter 当前为 DateTimeFormatter.ofPattern("uuuu-MM-dd")。
LocalDate date = LocalDate.parse("2026-09-27", formatter);
// 初始状态：date 当前为 LocalDate.parse("2026-09-27", formatter)。
// 作用：日期没有时分秒，适合生日、账期和截止日。
System.out.println(date.format(formatter));
// 输出：2026-09-27
```

### `LocalDate.format`：将日期格式化为文本

`date.format(formatter)` 使用同一个 `"uuuu-MM-dd"` 格式器，把日期恢复为 `"2026-09-27"`。

```java
String text = LocalDate.of(2026, 9, 27).format(DateTimeFormatter.ofPattern("uuuu-MM-dd"));
// 初始状态：日期为 2026-09-27，格式固定为 uuuu-MM-dd。
// 结果：text 为 "2026-09-27"
// 关键变化：String text = LocalDate.of(2026, 9, 27).format(DateTimeFormatter.ofPattern("uuuu-MM-dd")); 的返回值写入 text，调用后 text 保存该具体结果。
```

### `LocalTime.parse`：将文本解析为本地时间

`HH` 是 00–23 的 24 小时制；若业务使用上午/下午，要配合 `a` 和 `hh`，不要混写成 `HH a`。

```java
import java.time.LocalTime;
import java.time.format.DateTimeFormatter;

DateTimeFormatter formatter = DateTimeFormatter.ofPattern("HH:mm:ss");
// 初始状态：formatter 当前为 DateTimeFormatter.ofPattern("HH:mm:ss")。
LocalTime time = LocalTime.parse("09:30:15", formatter);
// 初始状态：time 当前为 LocalTime.parse("09:30:15", formatter)。
// 作用：HH 是 00–23 的 24 小时制。
System.out.println(time.format(formatter));
// 输出：09:30:15
```

### `LocalTime.format`：将本地时间格式化为文本

需要输出固定的 24 小时制文本时，`time.format(formatter)` 按 `"HH:mm:ss"` 得到 `"09:30:15"`。

```java
String text = LocalTime.of(9, 30, 15).format(DateTimeFormatter.ofPattern("HH:mm:ss"));
// 初始状态：本地时间为 09:30:15。
// 结果：text 为 "09:30:15"
// 关键变化：String text = LocalTime.of(9, 30, 15).format(DateTimeFormatter.ofPattern("HH:mm:ss")); 的返回值写入 text，调用后 text 保存该具体结果。
```

### `LocalDateTime.parse`：将文本解析为本地日期时间

它仍然没有时区，不能独立表示跨地区的唯一时刻；会议预约等业务还需要补充 `ZoneId`。

```java
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

DateTimeFormatter formatter = DateTimeFormatter.ofPattern("uuuu-MM-dd HH:mm");
// 初始状态：formatter 当前为 DateTimeFormatter.ofPattern("uuuu-MM-dd HH:mm")。
LocalDateTime value = LocalDateTime.parse("2026-09-27 09:30", formatter);
// 初始状态：value 当前为 LocalDateTime.parse("2026-09-27 09:30", formatter)。
// 作用：它仍然没有时区，不能独立表示跨地区的唯一时刻。
System.out.println(value.format(formatter));
// 输出：2026-09-27 09:30
```

### `LocalDateTime.format`：将本地日期时间格式化为文本

`value.format(formatter)` 保留 `value` 的日期和钟表读数，但输出仍不包含时区或偏移。

```java
String text = LocalDateTime.of(2026, 9, 27, 9, 30)
        .format(DateTimeFormatter.ofPattern("uuuu-MM-dd HH:mm"));
        // 关键变化：.format(DateTimeFormatter.ofPattern("uuuu-MM-dd HH:mm"));；当前对象；format；当前对象.format(DateTimeFormatter.ofPattern("uuuu-MM-dd HH:mm")) 返回转换后的具体值，赋给当前示例中的接收变量。
        // 初始状态：text 当前保存 LocalDateTime.of(2026, 9, 27, 9, 30) .format(DateTimeFormatter.ofPattern("uuuu-MM-dd HH:mm"))的计算结果。
        // 初始状态：LocalDateTime.format 用模式 "uuuu-MM-dd HH:mm" 格式化 2026-09-27 09:30，把文本写入 text。
// 结果：text 为 "2026-09-27 09:30"
```

### `DateTimeFormatter.ISO_*`：使用稳定 ISO 格式

接口和日志优先使用预定义 ISO 格式，避免团队各自拼接模式；`ISO_OFFSET_DATE_TIME` 和 `ISO_ZONED_DATE_TIME` 分别适合带偏移和区域的值。

```java
// 语义：接口和日志优先使用预定义 ISO 格式，避免团队各自拼接模式。
// 初始状态：event 初始为 Instant.parse("2026-09-27T01:30:00Z")。
import java.time.Instant;
import java.time.format.DateTimeFormatter;

Instant event = Instant.parse("2026-09-27T01:30:00Z");
// 初始状态：event 的初始值为 Instant.parse("2026-09-27T01:30:00Z")。
// 作用：接口和日志优先使用预定义 ISO 格式，避免团队各自拼接模式；ISO_OFFSET_DATE_TIME 和 ISO_ZONED_DATE_TIME 分别适合带偏移和区域的值。
System.out.println(DateTimeFormatter.ISO_INSTANT.format(event));
// 输出：2026-09-27T01:30:00Z
```

### `ofPattern`：按模式构造格式化器

常用字母要区分大小写：`MM` 月、`mm` 分钟，`dd` 日，`HH` 小时；模式应集中定义而不是散落在业务代码里。

```java
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;

var formatter = DateTimeFormatter.ofPattern("uuuu/MM/dd");
// 初始状态：formatter 当前为 DateTimeFormatter.ofPattern("uuuu/MM/dd")。
// 作用：常用字母要区分大小写：MM 月、mm 分钟，dd 日，HH 小时。
System.out.println(LocalDate.of(2026, 9, 27).format(formatter));
// 输出：2026/09/27
```

### `withLocale`：按地区格式化文本

月份和星期名称会受 Locale 影响；协议文本应使用固定 Locale，用户界面再根据用户地区选择本地化格式。

```java
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.util.Locale;

var formatter = DateTimeFormatter.ofPattern("dd MMM uuuu", Locale.ENGLISH);
// 关键变化：var formatter = DateTimeFormatter.ofPattern("dd MMM uuuu", Locale.ENGLISH)；formatter 接收 ofPattern("dd MMM uuuu") 的返回值，当前值变为这次调用得到的具体结果。
// 初始状态：formatter 当前为 DateTimeFormatter.ofPattern("dd MMM uuuu", Locale.ENGLISH)。
System.out.println(LocalDate.of(2026, 9, 27).format(formatter));
// 输出：27 Sep 2026
```

### `parse` 的异常边界：捕获格式错误

只在输入边界捕获并转换异常；不要用 `try/catch` 掩盖内部业务逻辑的日期错误。

```java
// 输入：LocalDate.parse 用 STRICT 格式器解析不存在的日期 "2026-02-30"，失败时进入 DateTimeParseException 分支。
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.time.format.DateTimeParseException;
import java.time.format.ResolverStyle;

try {
    var formatter = DateTimeFormatter.ofPattern("uuuu-MM-dd")
            .withResolverStyle(ResolverStyle.STRICT);
// 初始状态：formatter 的初始值为 DateTimeFormatter.ofPattern("uuuu-MM-dd")。
    // 关键变化：var formatter = DateTimeFormatter.ofPattern("uuuu-MM-dd") .withResolverStyle(ResolverStyle.STRICT); 将返回值写入 formatter；formatter 现在保存该具体结果。
            // 关键变化：.withResolverStyle(ResolverStyle.STRICT)；当前对象；withResolverStyle；当前对象.withResolverStyle(ResolverStyle.STRICT) 返回本次调用的具体结果，后续语句继续使用该值。
    LocalDate.parse("2026-02-30", formatter);
    // 关键变化：LocalDate.parse("2026-02-30", formatter);；LocalDate；parse；LocalDate.parse("2026-02-30") 返回转换后的具体值，赋给当前示例中的接收变量。
} catch (DateTimeParseException ex) {
    System.out.println("invalid date");
    // 输出：invalid date
}
```
## 不常用但需要知道
### `SimpleDateFormat`：兼容旧日期格式化器

旧接口需要它时应局部创建，不能在多线程之间共享同一实例。

```java
import java.text.SimpleDateFormat;
import java.util.Date;
var formatter = new SimpleDateFormat("yyyy-MM-dd");
// 输入：formatter 的初始值为 new SimpleDateFormat("yyyy-MM-dd")。
// 作用：通过 SimpleDateFormat 兼容旧日期格式化器。
String text = formatter.format(new Date(0));
System.out.println(text.length());
// 输出：10
```

### `LocalDateTime.of`：由字段构造本地日期时间

字段已经拆分且不含时区时，用它构造并立即校验日期时间。

```java
import java.time.LocalDateTime;
var value = LocalDateTime.of(2026, 10, 3, 9, 30);
// 输入：value 的初始值为 LocalDateTime.of(2026, 10, 3, 9, 30)。
// 作用：通过 LocalDateTime.of 由字段构造本地日期时间。
System.out.println(value);
// 输出：2026-10-03T09:30
System.out.println(value.getHour());
// 输出：9
```

### `LocalTime.of`：由字段构造本地时间

它只表达一天内的时间，不携带日期、时区或偏移量。

```java
import java.time.LocalTime;
var value = LocalTime.of(9, 30, 5);
// 输入：value 的初始值为 LocalTime.of(9, 30, 5)。
// 作用：通过 LocalTime.of 由字段构造本地时间。
System.out.println(value);
// 输出：09:30:05
System.out.println(value.getSecond());
// 输出：5
```

### `Duration.of`：按单位构造时间段

它把数值与 `ChronoUnit` 组合成基于秒和纳秒的时间量。

```java
import java.time.Duration;
import java.time.temporal.ChronoUnit;
Duration timeout = Duration.of(3, ChronoUnit.MINUTES);
// 输入：timeout 的初始值为 Duration.of(3, ChronoUnit.MINUTES)。
// 作用：通过 Duration.of 按单位构造时间段。
System.out.println(timeout.toSeconds());
// 输出：180
System.out.println(timeout);
// 输出：PT3M
```


### `DateTimeFormatterBuilder`：构造多个可选部分

构建器适合兼容多种输入格式；可选分支过多会降低协议清晰度，优先统一上游格式。

```java
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.time.format.DateTimeFormatterBuilder;

DateTimeFormatter formatter = new DateTimeFormatterBuilder()
        .appendPattern("uuuu-MM-dd")
        .optionalStart().appendPattern(" HH:mm").optionalEnd()
        .toFormatter();
// 关键变化：DateTimeFormatter formatter = new DateTimeFormatterBuilder() .appendPattern("uuuu-MM-dd") .optionalStart().appendPattern(" HH:mm").optionalEnd() .toFormatter()；formatter 接收 appendPattern(当前参数) 的返回值，当前值变为这次调用得到的具体结果。
// 输入：formatter 的初始值为 new DateTimeFormatterBuilder()。
System.out.println(LocalDateTime.parse("2026-09-27 09:30", formatter));
// 输出：2026-09-27T09:30
```

### `ResolverStyle.STRICT`：严格解析日期

严格模式拒绝不可能的日期；使用 `uuuu` 比 `yyyy` 更适合配合严格解析，避免 era 信息缺失。

```java
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.time.format.ResolverStyle;

var formatter = DateTimeFormatter.ofPattern("uuuu-MM-dd")
        .withResolverStyle(ResolverStyle.STRICT);
        // 关键变化：.withResolverStyle(ResolverStyle.STRICT);；当前对象；withResolverStyle；当前对象.withResolverStyle(ResolverStyle.STRICT) 返回本次调用的具体结果，后续语句继续使用该值。
        // 关键变化：.withResolverStyle(ResolverStyle.STRICT);；当前对象；withResolverStyle；当前对象.withResolverStyle(ResolverStyle.STRICT) 返回本次调用的具体结果，后续语句继续使用该值。
        // 初始状态：formatter 当前保存 DateTimeFormatter.ofPattern("uuuu-MM-dd") .withResolverStyle(ResolverStyle.STRICT)的计算结果。
System.out.println(LocalDate.parse("2026-09-27", formatter));
// 输出：2026-09-27
```

### `parseBest`：按输入字段选择结果类型

它适合兼容带不带时间的输入；返回类型不固定时，调用方要把类型分支写清楚。

```java
import java.time.LocalDate;
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.time.temporal.TemporalAccessor;

DateTimeFormatter formatter = DateTimeFormatter.ofPattern("uuuu-MM-dd['T'HH:mm]");
TemporalAccessor parsed = formatter.parseBest(
        "2026-09-27T09:30", LocalDateTime::from, LocalDate::from);
// 关键变化：TemporalAccessor parsed = formatter.parseBest( "2026-09-27T09:30", LocalDateTime::from, LocalDate::from)；parsed 接收 parseBest("2026-09-27T09:30") 的返回值，当前值变为这次调用得到的具体结果。
// 输入：parsed 的初始值为 formatter.parseBest(。
System.out.println(parsed);
// 输出：2026-09-27T09:30
```

### `DateTimeFormatter` 常量：重复使用线程安全格式器

格式化器不可变且线程安全，可以作为 `static final` 共享；不要为每次请求重复拼接相同模式。

```java
// 输入：共享的 DateTimeFormatter.ISO_LOCAL_DATE 将 LocalDate.of(2026, 9, 27) 格式化为标准日期文本。
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;

DateTimeFormatter formatter = DateTimeFormatter.ISO_LOCAL_DATE;
// 关键变化：DateTimeFormatter formatter = DateTimeFormatter.ISO_LOCAL_DATE; 将返回值写入 formatter；formatter 现在保存该具体结果。
System.out.println(formatter.format(LocalDate.of(2026, 9, 27)));
// 输出：2026-09-27
```

### `TemporalAccessor`：读取通用时间字段

通用字段适合格式化器扩展和框架适配；普通业务代码优先转换为具体的 `LocalDate` 等类型。

```java
import java.time.format.DateTimeFormatter;
import java.time.temporal.ChronoField;

var parsed = DateTimeFormatter.ISO_LOCAL_DATE.parse("2026-09-27");
// 关键变化：var parsed = DateTimeFormatter.ISO_LOCAL_DATE.parse("2026-09-27")；ISO_LOCAL_DATE.parse("2026-09-27") 返回转换后的具体值，赋给当前示例中的接收变量。
// 初始状态：parsed 当前为 DateTimeFormatter.ISO_LOCAL_DATE.parse("2026-09-27")。
System.out.println(parsed.get(ChronoField.DAY_OF_MONTH));
// 输出：27
```
## 简单案例

```java
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

public class DateFormatDemo {
    public static void main(String[] args) {
        DateTimeFormatter input = DateTimeFormatter.ofPattern("uuuu/MM/dd HH:mm");
        DateTimeFormatter output = DateTimeFormatter.ofPattern("uuuu-MM-dd HH:mm:ss");
        LocalDateTime value = LocalDateTime.parse("2026/09/27 09:30", input);
        System.out.println(output.format(value));
        // 输出：2026-09-27 09:30:00
    }
}
```

## 易混点

- `MM` 是月份、`mm` 是分钟；`HH` 是 24 小时、`hh` 是 12 小时，格式模式大小写不能混淆。
- `LocalDateTime` 的格式化结果没有时区，不能据此推断全球唯一时刻。
- `uuuu` 适合 `java.time` 的年份和严格解析，`yyyy` 表示 era 里的年份，边界语义不同。
- `DateTimeFormatter` 是线程安全的，旧式 `SimpleDateFormat` 不是；新代码应优先使用 `java.time`。

## 课后小问

1. 为什么接口日期建议集中使用 ISO 格式？
   - 答案：ISO 格式明确、跨语言一致，且可以直接由 `java.time` 的预定义格式化器解析。
   - 解析：团队自定义格式如果没有统一文档，很容易出现月份/分钟或时区字段误读；协议应稳定优先。

2. 为什么严格解析常用 `uuuu` 而不是 `yyyy`？
   - 答案：`uuuu` 直接表示 proleptic year，和 `java.time` 的严格解析语义更匹配。
   - 解析：`yyyy` 是 year-of-era，严格模式下可能需要 era 信息；使用 `uuuu` 能避免常见的解析冲突。

## 本节小结

- 解析把文本变成结构化日期，格式化把日期变成外部文本，二者都需要明确格式。
- `LocalDate`、`LocalTime` 和 `LocalDateTime` 分别表示日期、时间和无时区的日期时间。
- `DateTimeFormatter` 可按模式、ISO 常量或构建器创建，并且可以安全共享。
- 严格校验、Locale 和异常边界决定了外部时间输入是否可靠。

## 快速回顾

- 能正确区分 `MM`/`mm` 与 `HH`/`hh`。
- 能为协议选择 ISO 格式，为界面选择 Locale 格式。
- 能使用 `uuuu` 和 `ResolverStyle.STRICT` 校验日期。
- 能在解析失败的输入边界处理 `DateTimeParseException`。
