## 怎么查

- 想快速写代码：进入对应文章的“常用用法”，按 API 小标题查找可运行的 `python` 示例和紧邻的 `# 输出：...`。
- 想确认边界：查看“不常用但需要知道”，重点看版本差异、异常行为、性能或资源释放要求。
- 想从零学习：按基础篇 01–17 顺序阅读；数据栈和 PyTorch 适合作为基础语法之后的专项出口。
